W3-07 删除人工非 AI 文件同步进入 ready、把原文件当作样片水印档位的桥接。
注册仅声明真实制作上下文；入库后使用既有 probe、补标、样片水印任务与结果回读。
`deliveryProductionFacts` 在调用者事务内重核当前上下文、规则版本、真实输入 SHA、
任务输入输出、体检快照、AI 与派生来源。商家样片访问还必须匹配真正的水印产物。

`delivery.onProductionChecked` 只处理当前 uploaded 版本，重复和旧版本不覆盖新版本。
通过只回写实际正时长；人工 QC、上传人与质检人分离、推送与下载证据沿原流程。
拒收释放原专属引用并保留原 30 天来源期。API 与 worker 各持自己的订阅者闭包，
关闭后拒绝调用，不能回退到另一运行时。

AI 文件只有同上下文、同规则、固定去重键且未过期的实际补标任务才能等待派生结果。
派生替换同时核验成功任务输出、文件 SHA/大小与实际下游体检，保留原上传人。
补标在 pending 被观察后失败时可能保持 uploaded，但 QC 始终拒绝；恢复沿已有
审计重试或重新上传，不新增自动拒收事件或补偿定时器。旧成功 probe 缺少输入摘要的
记录不伪造 SHA；旧缺字段结果按既有 MEDIA_RESULT_INVALID 与审计重试处理，
已完成而缺少摘要的历史文件须重新上传后取得可核实事实。

数据库与 API 用例的 typed codec/cloud 替身只替换外部媒体操作，真实执行任务领取、
体检、引用、状态与订阅者。live 使用本轮合法媒体、固定镜像真实探测与 PNG 叠加；
CLI 的有界等待只读当前任务和来源事实，不是另一套业务准入。live 对已持久化的本轮
checked 事件直接调用同事务绑定的订阅者，不伪造 ACK、inbox 或 delivery，不能称作
真实 dispatcher 全链验证。真实云、平台读标与真机联调另验。

旧同步桥用例的正向期待改为 uploading、没有播放资产且真实 probe 已排队；原拒收、
AI pending、normalized、错上下文负例和 60 秒期限保留。原失败证据独立留存。

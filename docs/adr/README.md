## 1. 与 04 的关系

| 项 | 规则 | 出处 |
| --- | --- | --- |
| 04 收什么 | 建仓前的首批决策 ADR-001–ADR-040。不再往 04 里加新条目 | 04 文首 |
| 本目录收什么 | ADR-041 起的全部新决策 | 04 文首；开发计划 第 5.1 节 |
| 04 里“提议”的 37 条 | 按提议执行。验证结论把相关 ADR 转为“已定”或修订 | 开发计划 第 3 节前提 ⑫ |
| 改 04 里某条的状态 | 默认：直接改 04 里那一条的标题括注（如“提议”改“已定，依据 ADR-0NN 或验证项编号”），原文不删（W0-04 定） | 04 文首“状态约定” |
| 修订或推翻 04 里的某条 | 在本目录新写一条，写明“取代 ADR-0NN”；04 里那一条保留原文，标题括注改为“被 ADR-0NN 取代” | 04 文首“状态约定” |

## 2. 什么时候写 ADR

| 情形 | 要不要写 | 出处 |
| --- | --- | --- |
| 架构取舍（与 01–07 的做法不同，或 01–07 没定而必须定） | 写 | 开发计划 第 13 节“计划变更怎么记”行 |
| 技术验证有结论：X-01–X-04、V4 | 写；同时更新开发计划 第 8.6 节与外部验证台账 | 开发计划 第 6.3、7.4 节 |
| `spikes/` 下的验证代码要删 | 先把结论写进 ADR，再删 | 开发计划 第 5.1 节 |
| 首版迁移、Prisma 与手写约束的处理结论 | 写 | 开发计划 第 11 节风险 3 |
| 包的拆并、顺序调整、估算修正、条目改归属 | 不写 ADR，记 `docs/plan/changes/` | 开发计划 第 13 节 |
| 里程碑范围、退出条件、前提的改动 | 不写 ADR，PR 标 `plan-change`，业主确认 | 开发计划 第 13 节 |
| 待确认事项（Q）有了结论 | 先改文档里的默认做法，再改代码，同一个 PR；属于架构取舍的另写 ADR | 开发计划 第 13 节 |

里程碑结束时核对“ADR 补齐”（开发计划 第 10.2 节）。

## 3. 文件与编号

| 项 | 规则 | 出处 |
| --- | --- | --- |
| 一条一文件 | `docs/adr/NNNN-标题.md`。`NNNN` 是四位编号，补零 | 04 文首 |
| 编号 | 从 041 起接续 04，即第一个文件是 `0041-<标题>.md`，文内写作 ADR-041。编号只增，不复用 | 04 文首；开发计划 第 7.2 节 W0-04 |
| 何时取号 | 编号在合并时分配，避免并行分支撞号 | 04 文首 |
| 合并前怎么写 | 默认：分支上文件名用 `draft-<工作包编号>-<标题>.md`，文内编号写“ADR-待分配”。合并前最后一次与 main 同步时，取 main 上最大编号加 1，改文件名与文内编号，并改掉同一个 PR 里的引用（W0-04 定） | — |
| 撞号 | 默认：后合并的一方重新取号，由作者会话或维护会话改（W0-04 定） | 开发计划 第 5.3 节“维护会话”行 |
| 标题 | 中文短语，写决定本身，不写问题。文件名里的空格换成 `-` | 默认（W0-04 定） |
| 索引 | 默认：不手写索引表，目录列表即索引，避免并行 PR 冲突（W0-04 定） | 开发计划 第 13 节“一包一个文件”的同一做法 |
| 引用写法 | 文内写“ADR-041”；跨文档链接到文件 | — |

## 4. 状态取值

| 状态 | 含义 | 谁改 | 出处 |
| --- | --- | --- | --- |
| 提议 | 待确认。按提议执行 | 作者会话，随 PR | 04 文首；开发计划 第 3 节前提 ⑫ |
| 已定 | 评审通过，或验证结论支持。写明依据（业主确认、验证项编号） | 合并该结论的 PR | 04 文首 |
| 被取代 | 有新 ADR 取代它。保留原文，注明取代它的编号 | 写新 ADR 的同一个 PR | 04 文首 |

默认：只有这三个值，不另设“废弃”“拒绝”。没被采纳的方案写在采纳那一条的“放弃的备选”里（W0-04 定）。

## 5. 正文格式

| 栏 | 写什么 | 可否省略 |
| --- | --- | --- |
| 背景 | 遇到了什么、有什么约束。引用写“文件 第 N 节” | 没有内容的项省略 |
| 决定 | 一两句话说清做什么 | 不可省 |
| 理由 | 为什么这样定；验证类写实测结果与证据链接 | 没有内容的项省略 |
| 放弃的备选 | 每个备选一句，写为什么不选 | 没有内容的项省略 |
| 代价 | 这样做要付出什么、留下什么限制 | 没有内容的项省略 |

五栏照 04 文首“每条的格式”。文首的属性表（状态、工作包、取代关系、回写了哪些文档）是默认（W0-04 定），见模板。

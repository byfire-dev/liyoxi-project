本片 SOURCE 尚待唯一串行窗口执行 fresh 类型、完整旧新单测、构建/预算、默认全量截图和必要门禁，不把轻检查记为通过。普通 file 无 ListMultipartUploads，manifest 丢失不能发现旧孤块；未知回执和损坏记录不盲目再初始化。临时文件跨重启、真实签名/域名/服务端取消和内存峰值须真机与真实云验证，H5 不证明这些能力。详细可证明边界见 `apps/weapp/README.md` 的微信分块上传构件节。

## 偏差

经主调度按 CLAUDE 第7节核准必要伴随：StorageProvider 增加有界 `readTo` / `putStream`，流式逐块验证实际大小与 SHA256；kernel 仅增加已有 Provider 守卫的工具装配出口；L4 通过现有同事务公开事实读取门店、广告与短剧上下文，未扩层白名单。原五事件补登记严格载荷、封面/来源引用沿既有角色及保留期，无新 HTTP/page/x01/DDL/依赖。

腾讯原生 Text 水印不接受正式样片文案中的标点与空格，因此采用固定许可 Noto CJK 字体渲染透明 PNG，再使用同桶固定对象的原生 Image 水印。字体二进制、来源、版本、SHA 与 OFL 许可证单独登记；不改正式文案，不复制系统字体，不升级基础镜像。真实云模板、云水印及法务 AI 编码仍未验证。

实际 store 简称端口不存在，组合根改为同事务公开门店 name 事实，shared 按正式规则清洗、截取10字。测试工具仅可在 local/test 且完整制作配置时注入；固定 TX 外呼守卫、自有取消及关闭、真实领域事实不替换。对外就绪事实仍必须由五处理器实际收尾，不允许 fixture 直接写 ready。

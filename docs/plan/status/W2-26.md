## 已验与没有验的

已验：真实 Node CLI 经假受限 SSH 执行真 bash，发布顺序、逐步失败停止、同版本重跑、CI JSON/摘要写入；回滚先 api/gateway 后 worker，不调迁移/补种/资源预置，本地缺镜像和任一跨过的不安全记录会拒绝，越过需 force 与非空理由。真实 bash 加假 Docker/systemd 核资源不覆盖、停止等待与 60/30 秒上限、readyz 连续三次 200、超时、P1 查询失败、限定镜像/资源清理、严格 JSON 追加和 SSH 注入拒绝。Node24 下本包 38 项与原 W2-25 的 61 项（合计 99）通过；infra 类型、改动文件 lint、全仓 format、depcheck 与 rename 通过；普通 CI 由调度在 PR 收口。

没有验：没有登录预发节点、读真实密钥、启用工作流或上传体验版，没有运行本包的真实 Docker 发布与回滚演练；原 W2-25 演练加资产预置的真实容器路径由普通 CI 核验。a 的 smoke 只核 API 真探活、两个前端入口、真实构建号与 worker；全资源与持续探测、完整结构核对、上传和工作流由 b 交，不把本地编排测试写成预发发布完成。外部验证仍待预发实跑。

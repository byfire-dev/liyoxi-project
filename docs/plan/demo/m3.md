# M3 本地接口演示

入口 `pnpm demo:m3` 与 `pnpm e2e:m3` 共用正式接口链。后台建剧、上传两集原片、
体检上架后，商家上传素材、后台整理与确认肖像授权，再订购、制作、质检、交付和上线。
沿用 M1 隔离支架；新增 M3 使用两集和单路上传，原 M1 二十集默认不变。

## 运行

先按根 README 安装锁定依赖、生成数据库客户端，并确认本机 PostgreSQL 和 Redis 已就绪。
以下是仓库公开的本机开发连接值，无需读取 `.env`：

```sh
export APP_ENV=test
export DATABASE_URL=postgresql://liyoxi:lyx-local-dev@localhost:5442/liyoxi
export REDIS_URL=redis://localhost:6389/0
pnpm demo:m3
pnpm demo:m3
```

每次命令拥有新的隔离测试库和 Redis 前缀，结束后只清理自己的资源；不接受生产或远程业务库。
因此两次命令的 UUID 不相同。每次命令内部在同一库上执行同一演示意图两遍：
第一遍经后台 HTTP 创建并上架内容、完成商家链；第二遍复用原意图，
复跑公共前置种子与内容演示，逐项比较相关业务表数量及字典快照，新增数必须为零。
这个同库第二遍才是幂等证据，不把第二个新库的重新造数称为零新增。

## 演示边界

以上使用真实本机 PostgreSQL、Redis、正式鉴权/权限/幂等/业务状态机和事件订阅。
存储、微信、OCR、ASR、模型及媒体 codec 外呼使用测试替身；固定视频和 SHA 绑定的实测报告
沿用 W3-04/W3-07 证据，不代表此命令重新执行原生视频探测或验证水印像素。
真实云桶、微信回调/相册、识别准确率、费用及预发大文件公网性能仍按 E4/E17/E19/E22/V11 台账外验。
不要以修改数据库状态、放宽检查项或重置共享本机容器来完成演示。

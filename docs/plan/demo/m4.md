# M4 本地资金接口演示

离线发布说明（2026-10-27）：下文演示与main记录保留原本地完整组合的验证事实。本第1个PR交演示实现；根demo:m4命令与说明随第3个CI只增PR接入，repeat随第2个独立门禁PR交付。当前W4-19远端交付仍进行中，本次打包未重新运行演示。

`pnpm demo:m4`复用`e2e:m4`的资金runner：真实Hono路由、登录/权限、幂等、状态机和本机数据库，外部渠道使用公开替身。每次命令拥有新的隔离范围，内部再核一次原演示意图，最后只清理本轮资源。

适配器、runner hook、完整资金链及根命令入口均已独立审查并合入本地main `6740eb60`。在该main连续两次执行演示均通过，同范围原意图重放业务新增0、完整字典保留，134项全量不变量零违规/零错误，原90秒含清理上限通过；类型覆盖与生产环境拒绝也已通过。

## 运行环境与命令

使用根README规定的Node24、锁定依赖和当前官方生成数据库客户端，确认本机PostgreSQL/Redis已就绪。公开开发连接如下，不需要读取`.env`或配置真实支付密钥：

```sh
export APP_ENV=test
export DATABASE_URL=postgresql://liyoxi:lyx-local-dev@localhost:5442/liyoxi
export REDIS_URL=redis://localhost:6389/0
pnpm demo:m4
pnpm demo:m4
```

每次命令新建独占测试库和Redis前缀，因此两次命令的业务ID/单号可以不同。每次命令都在自己的同一范围内证明第二遍零新增，不把另一个新库重新造数称为幂等。初始化、主链、同范围重放、全量不变量及自然清理合计仍须≤90秒。

仅支持`--help`；帮助输出不运行资金链。执行不接受`--stack`、attach、任意业务库或保留测试库参数。非test环境在创建隔离资源前拒绝：

```sh
APP_ENV=prod pnpm demo:m4
```

预期退出码1，stderr为固定的test环境限制说明，且不创建隔离资源；`APP_ENV=production`、local及未声明环境同样拒绝。prod与production均以不可连接的本机测试地址实测，在资源创建前进入明确环境拒绝分支，分别1.93秒/1.40秒、退出码1。

## 同一范围第二遍

首核心退款完成后，runner的`afterCore`只交出本轮entityId和原意图重放闭包，不交出登录头、口令、令牌或完整响应。闭包保留首轮付款/退款创建的原key、原正文、业务ID及两条原通知，真实重放后核对同ID、钱包、退款/收款流水及权益唯一，不重新试算后另建业务。

testing核验器先检查test环境、本机连接、runId对应的测试库/Redis范围以及`current_database()`实际归属，并沿原支架确认已有真实退款事实。随后记录32张明确业务表的逐项数量和完整字典，复跑原公开演示种子并要求`inserted=0`，再执行原意图闭包和事件消费。前后各表数量必须逐项相等，字典类型和全部条目连同停用、扩展、版本完整相等，才返回`inserted=0`、`dictionaryPreserved=true`。

数量比较限于本轮独占测试库，包含付款、退款、审批、调整、延长、积分、配置、文件/引用及原建档等业务表；不把会话、事件投递和不变量运行等技术记录计作新增业务。原资金读回检查继续保留，全量不变量仍由runner在后继链完成后执行一次，不以计数代替账务不变量。

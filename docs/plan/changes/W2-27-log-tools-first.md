# W2-27：a 内先交独立日志入口

调度允许从原 a 先交 `logs`/`log-stats` 两个只读入口；编号、包数与整包退出判据不变。依赖 W2-25/26 均已在开工基线 local main c7c28f3。

本块含 gateway JSON 流统计、六服务请求编号查询、有限输入/聚合、当前版本镜像只读 helper、原完整 stg-node 与新日志目标。非测试改动上限550行、测试750行，文档单列。无依赖、HTTP、DDL、apps/packages、任意endpoint、真实远端或密钥操作。

a 后继仍负责正式轮转矩阵、Redis清空及120秒恢复、六容器真实演练；b 仍负责告警/错误上报配置和真实接通、源码映射。W2-27保持进行中；日志入口不能冒称 a 或整包完成，也不能据此宣称 W2-29 的整包前置已退出。

统计与查询的命令、边界和失败处置见[运行手册](../runbook.md#211-按请求编号查日志与-gateway-统计)。本机 Docker helper 如另获授权仅证明隔离读取，不替代原六容器演练；服务器操作仍由业主执行或逐步授权。

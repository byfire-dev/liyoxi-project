此变更依据原 W6-10 第6节的依赖缺口流程独立交付，不消费未合安全壳或 Portal Playwright 前置。只增加工具声明，不新增入口、配置、生产依赖或测试成功记录；安全壳与真实扫码的前置、验收和完成状态均按原任务办理。

从已接纳 main8e11c286 开始，不消费在途门店创建候选。
Billing 复用钱包现算，scheduled 存在独立判断；非 active 取最近创建付款单。
四种付款类型与完整快照必须匹配；套餐名读真实 plan，升级沿目标版本定位套餐。
缺账户、损坏快照或引用不伪装零值；主体不存在按 NOT_FOUND。
Profile 只读地址、最近审核决定、当前已提交开放轮次及复制来源，不加载证照文件。
停用字典保名称，缺码保原 code；不存在档案是合法空字段，不新增档案。
Media 单语句取得每店未删除/已整理/复制数和主体全店成员上传/采用条数。
历史上传不因成员移除而丢失；采用多次只算一条，成员级排除 staff，两级均排除软删素材。
请求门店必须真实属于主体，foreign/missing 整批 NOT_FOUND；空集合不证明主体存在。
三个读口沿调用方事务，无锁、推进、缓存、自有时钟、外部 IO 或写入。

`lyx_14_analytics_event_retire_partition(date,timestamptz,integer,bigint,text)`
只处理固定 `analytics_event` 的规范月分区。保留期沿正式参数 13–60，默认仍 25；
月界取 Asia/Shanghai，只退役完全过期月份。父表独占锁下复用已合入结构/guard
校验并核实际全量行数，才原子 DETACH/DROP，无 CASCADE；缺失分区返回 false。
PUBLIC/readonly 无执行权，只授 app；原表只增与禁 DELETE/TRUNCATE 保持。

数据库不能验证对象存储。可信业务服务须先分批导出完整 21 列，逐块验证对象，
再写入并验证包含完整块清单、哈希、大小和行数的不可变 manifest，最后提交
总行数及 manifest SHA-256。源只增，父锁内行数失配拒绝删除；迟到插入要重新
归档，不能以最大 UUID 或 Provider 上传受理代替完整性。时钟/参数来自服务，
函数不是失陷应用凭据的归档防伪协议，也不处理 DEFAULT、dedup 或 identity。

测试使用小批完整合法数据与真实非超级用户，验证参数/保留边界/权限/重放、
完整行数、等待锁期间的迟到插入、事务回滚、错误对象/边界/guard 与 search_path。
不放大样本或改变原并发断言；本机通过只说明这些正确性判据，正式容量另验。
本地新能力与原授权 79 项、原分区与首版迁移 23 项通过（102 项）；现行/冻结目录、

# W2-14 邀请页先交请求层用户范围构件

| 项 | 内容 |
| --- | --- |
| 改了什么 | 按开发计划第 5.3 节的构件粒度及 W2-14 任务书第 5 节冻结边界，六页开工前先独立交付中央 request 的 typed `store: false` 选项，仅省略 `X-Store-Id`。W2-14 六页、接口、里程碑与包数不变。 |

邮件驱动前置已实际合入 main（95a97116）。本片仅追加可选 mail overlay、固定选择器、独立密钥清单及文档。
MAIL_TENCENT_FILE 只挂 worker 和离线 check-env；API、基础配置与其他角色不增加邮件密钥。
沿用固定名字、普通文件、0400/UID1000、未选中降级和原密钥检查，不生成或读取真实凭据，不部署或发送邮件。

既有精确角色测试只追加 mail 组，旧组和全部断言保留。此测试叶单独提交到 codex/w4-13-mail-config-gate，
配置五叶随后提交 codex/w4-13-mail-config；两部分配套集成，测试分支单独不代表功能交付。
两项定点配置验证首轮 2/2 通过（3.90 秒，另外 66 项未选），无数据库、Docker 或真实云服务。
六叶唯一非作者审查 71.231 秒，首尾 hash 一致、无 P1/P2/D。格式、ESLint、shell 语法与差异检查通过。
分类器将测试中沿用的 --skip-owner 夹具识别为放松，故测试叶独立 gate-change 提交；仅测试临时文件跳过宿主 UID，生产检查未改变。
配置分支不含门禁改动；静态与受控脚本验证不代表预发部署或真实邮件受理/送达。

# W3-15 worker 模型装配与关闭

| 项 | 内容 |
| --- | --- |
| 改了什么 | worker消费已解析ASR/LLM配置，登记实际驱动close；入口和运行时共享本实例关闭Promise，COS普通GET补齐两小时上限。 |
| 原因 | FILE解析与工厂已接受，生产worker尚未选择模型或承担部分构造失败的关闭责任。 |
| 影响的包 | packages/services的ops组合根、apps/worker入口与runtime、providers说明和W3-15状态。 |
| 类别 | 实现细化。 |
| PR | 本地开发分支，尚未建立PR。 |

基于实际main `e92d10f228c72bf1e71251e65b2e45370c5e4c60`，十个具名路径。
配置通过原kernel工厂，ASR用该实例时钟，LLM原主备、请求与总期限保持；不增加生产
transport/URL/超时覆盖。完整配置必须配对登记与关闭，借用整套providers不消费此口。
入口先持关闭列表，自检、租约、构造或start失败仍取消所有已登记驱动。
正常关闭先禁预算准入并drain业务，allSettled模型后才预算/告警；一个失败仍等其它关闭，
入口最后用缓存Promise兜底，实际驱动只关闭一次，不关闭借用基础设施或其它实例。

COS普通GET仅上限3600→7200一个字面量，匹配D5转写两小时；ASR原7200、视觉3600、
业务分类TTL与签名算法保持。真实桶、ZIP三小时签名的独立缺口不在本片验收范围。
原41个完整旧测试1565静态候选保持字节；只沿固定env105和vision105显示名多重集例外，
其它新旧重复一律拒绝，实际数量与通过状态留待授权完整执行的官方JSON。
当前仅SOURCE/轻静态，尚未执行types、收集、测试或连接DB/Redis/模型平台。
API不启用模型；默认2000/0、冷账本与缺配置降级保持，不初始化、恢复、退款或绕过预算。
模型构造零HTTP不等于worker基础设施零网络；真实平台/密钥、云权限、地域隐私/E22、
费用、质量、生产容量和完整W3-15均未验。

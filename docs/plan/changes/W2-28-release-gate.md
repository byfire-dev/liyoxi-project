调度批准同时更新两个既有门禁字面量：发布摘要 run-id 从触发 run 改为同 SHA 已核成功的 images run，不删身份断言；新目标覆盖先验顺序。整个 mixed-smoke job 上限十分钟，CI 主命令八分钟后发 TERM并留三十秒清理，本地编排原十分钟上限不变。仅保存白名单 JSON；本机共享依赖的生命周期不由该 CI 清理命令管理。

本片提交前只做本机纯验收；不触发 GitHub Actions、不部署或声称真实双版本四步通过。执行器必须先实际合入，随后该门禁才合流；整包与 W2-29 等待原完整判据。

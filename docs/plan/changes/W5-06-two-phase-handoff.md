## 2. 正式启用与验收口径

- 主文N6完整语义不变：①②同一writer真实heal，③只报告，ready文件实际哈希及版号连续仍检查。06.PR1不注册恒零/空实现或加条件跳过，不删除actual main已在役的N5/N4/N13。
- N6正式登记是06同包后片尚未交付项，06持续进行中，不新建stub、CI映射或新x01；原11桩及最终M5清零条件保持。仅07凭PR1真实回执开工，任务README §7.2由调度核公开源码、独审/验收与actual合入，不改summary脚本或虚造分片编号。
- 07排空必须等实际docs任务及ready条件提交、issued后续；outbox为空、subscriber done或队列waiting为0均不能单独证明render完成。后台observer保持只读，消费者完成真实写入，不SQL造ready、不把旧ready指针当本轮任务完成的证据。
- 保留初轮M1全链N6失败记录。06.PR1 full仅覆盖当时已登记集合，即使零违规也不得称完整N6已验；06.PR2须确认正式N6实际执行及真实M1 full零违规。核心/P95小样本通过不覆盖全链失败。
- 缺字出件选择按业主2026-10-30明确决定回写ADR-042及业主清单：暂停该版出件，提示具体缺字，修正资料或字体后重试。字体修正按原规则重渲同一不可变版次，资料修正更正重出生成新版，不回写旧snapshot。此决定不扩大X-03通过范围，不将E8/E11、真实签名或签后V12改为完成。

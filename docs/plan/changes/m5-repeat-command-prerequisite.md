# M5 repeat 命令白名单独立前置

| 项 | 内容 |
| --- | --- |
| 改了什么 | 按 W5-15 任务书第 3、4 节先独立扩展共享 repeat 执行器：具名命令白名单由 M1–M4 增加精确的 `e2e:m5`，补精确派发、缺失脚本和任意命令拒绝的定点反例。本片按 `gate-change` 单独交付。 |
| 原因 | W5-15 合流需复用原执行器；命令白名单的放宽须先与业务链分开评审，不能把白名单已允许当作 M5 命令或完整业务验收已交付。 |
| 影响的包 | 仅 W5-15 的 repeat 门禁前置；W5-15 actual 依赖、M5 范围和退出条件均保持。后续 wrapper、`e2e:m5` 脚本、CI 目标和业务链仍由实际依赖合 main 后的 W5-15 交付。 |
| 类别 | 顺序 |
| PR | 待调度会话独立审查、正常提交及远端 required 验证；本地定点验证不代表远端 CI 或 W5-15 完成。 |

原默认十轮、每轮 90 秒、独立 scope 顺序运行、失败即停、自然清理和 CLI 禁止命令覆盖保持；没有新增 wrapper、脚本或 workflow，也不更改 W5-15 状态。缺失脚本反例在仓库外一次性目录实际执行 `pnpm e2e:m5`，应首轮失败、成功 0、失败 1、未执行 9，并保留失败日志及部分汇总。

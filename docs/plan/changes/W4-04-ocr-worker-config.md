# W4-04 异步回单 OCR 的 worker 配置接线

| 项 | 内容 |
| --- | --- |
| 改了什么 | 可选OCR overlay与密钥清单增加worker角色，既有角色隔离测试只更新此组的精确预期 |
| 原因 | W3-16只有API同步证照识别；W4-04回单识别在worker执行，原节点配置不会把OCR文件挂给worker |
| 影响的包 | W4-04回单OCR前置、W2-25可选Provider接线；默认未选中时仍不挂载，无真实节点操作 |
| 类别 | 必要配置与门禁伴随 |
| PR | 配置 codex/w4-04-ocr-worker-wiring；单叶测试 codex/w4-04-ocr-worker-gate（gate-change）；须待回单OCR运行时前置实际合入main后成组合流 |

只新增worker的`OCR_TENCENT_FILE`及单文件secret引用，API/check-env原挂载保留。其他组、基础配置、文件权限和未选中时降级规则保持；不改驱动、识别字段、运行角色之外的密钥访问或任何部署开关。

原角色隔离聚合定向1/1通过（115ms，断言5ms）；其余66项未选，不启动Docker或数据库。五叶唯一非作者审查无P1/P2/D，首尾冻结hash一致；审查未采集耗时，不宣称计时达标。格式/ESLint、台账和差异检查通过。运行时前置与真实云识别、CAM权限、预发节点挂载分别记录，不能用配置静态验证冒称上线。

分类器将已有测试预期变更保守判为一项放松：原五叶混合分支不能作为 gate-change 提交，故仅将这一叶拆成独立门禁分支；配置四叶以它为基线。独立门禁分类已通过（只增0、放松1），上述定点验证针对两分支组合，拆分不改已审生产/测试内容。两部分须配套集成，单独测试分支不代表配置已经交付；不改分类规则或删除原隔离断言。

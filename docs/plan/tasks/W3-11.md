要落地的接口（11条）：

| operationId | schema/约束 |
| --- | --- |
| `m.drama.search` | q1–20、limit默认20/max50/opaque cursor、optional/catalog.read/trimmed，GET零写 |
| `admin.homeBanner.batchReorder` | 1–200不重复且恰全部未结束id集合，咨询锁/required/C50 |
| `admin.homeBanner.create` | 正式图分类/stored/非block、jump schema/上限与时间窗/required |
| `admin.homeBanner.list` | 正式displayState/isEnded分页，服务端actions/签图按窗口 |
| `admin.homeBanner.summary` | 全量计数+maxActive，GET零写，不随列表筛选变化 |
| `admin.homeBanner.update` | lockVersion/正式PATCH语义，启用时重校验目标/数量/时间窗 |
| `admin.siteConfig.draft.replace` | configKey/content整份schema、baseRevNo、草稿lockVersion|null、required |
| `admin.siteConfig.get` | published/draft/refs.invalidRefs与affectedBanners真实读侧 |
| `admin.siteConfig.publish` | 刚返回draft.lockVersion+页面baseRevNo，两锁/required，失效引用拒绝 |
| `admin.siteConfig.revision.list` | 修订分页/历史只读，rollback生成新草稿后发布 |
| `admin.siteNotice.list` | SiteNoticeItem/AdminPage、ops或billing查看，既有规则变更公告只读 |

表：site_config_revision/home_banner/site_notice、file_ref/audit；目录drama/genre/industry公开事实，零新表。
状态：site_config draft/published/archived；Banner用时间/启用字段派生displayState，规则公告按既有announced/withdrawn事实。
事件/timer/x01/page：无新增；站点/Banner提交后使site缓存版本加一，不伪业务状态事件。
草稿保存只schema校验，不阻引用、不改商家缓存；发布先锁草稿比lockVersion，再锁published比baseRevNo，先归档旧版再发布新版。
商城all固定分类不能删/隐藏/带题材，最多10分类/8热词；分档≤6、权重整数合计100，首页展示3–12、新剧范围7–90，引用发布时复核。
CatalogRefPort.areListed按当前可见/可订事实判定，题材启用/行业合法；发布后失效项后台标红、商家隐藏，不用缓存旧真值。
失效商城分类Banner只作affectedBanners提示不挡站点发布；首页跳过其失效跳转，不悄改Banner目标/假成功。
Banner上限与创建/编辑/排序咨询锁一致，排序包含停用但未结束行；换图link新/旧unlink保留180天，签图同key重放为null+replayed。
公告条按announced/barEnabled/时间窗/最新事实、购买入口策略选summary或summaryNoPrice；hidden/clerk/guest不得泄露老板价格/购买入口。
搜索只在可见目录中做，去空格/“·”；title包含优先，genre显示名双向包含，cast包含；matchedFields真实、稳定排序游标/totalApprox≤999。
未命中且关键词等于二级品类名时取父一级行业推荐；catalog.search.industry_fallback已有正式布尔参数默认true，关时空结果，不另建flag。
搜索复用实际角色/套餐价格裁剪与60秒目录快照；m.drama.list的q也用同份三字段匹配但不做行业兜底，热门词读已发布mall配置，历史不建表/不上传。

## 5. 不做什么

- 不改DDL/冻结metadata/层级/缓存机制，不让config直读content上层表或另写可见/可订公式。
- 不建公告CMS/V1.1管理/新x01/page，不为search加自由文本埋点或把历史上报。
- 不做索引迁移/搜索引擎、外部推荐、后台五页/小程序搜索UI，不打开预告片feed默认开关。
- 不对真实站点发布/Banner/协议公告执行操作，不配真实存储或发送通道。

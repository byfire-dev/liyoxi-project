实现腾讯云COS StorageProvider与真实直传/入库，不再以本地小文件通道冒充STS或版本控制。

不新增页面；给W3-02批量上传与后续媒体工作提供公开存储原语，真实云配置留业主办理。

要落地的接口（2条）：

| operationId | schema/约束 |
| --- | --- |
| `admin.file.cancel` | 本人staff上传、required；pending→expired，确认中拒绝，已expired自然回当前状态 |
| `admin.file.refreshCredentials` | 本人/none；FileRegistration，multipart STS30分钟、最多30次，凭证不存幂等结果 |

表：file_object、file_ref、media_job；状态沿pending/promoting/stored/rejected/expired，不创业务状态机。
事件沿complete的file.uploaded/file.rejected、promote的file.stored；取消无事件/审计，事务后尽力中止写入区分块。
页面/timer/x01：无新增；W3-03接管统一循环才删除promote旧30秒补偿扫描，本包不提前去掉兜底。
四桶secure/asset/media/pub及类别矩阵取共享登记，incoming只能写入区；不向客户端给正式区写权限或永久密钥。
续签原子复核pending/confirming/期限与sts_issued；短凭据只限定本人file前缀，none成功响应no-store，不缓存凭据。
complete仍三段式、绑定etag/大小/最多4KB头校验；promote条件复制后核正式对象，不采信客户端MIME/CRC成功声明。
按能力区分STS/versioning；MinIO unsupported不能假configured能力，stg/prod不得fallback本地驱动。
分块默认8MB、文件并发3/块并发4；失败/续签保留UploadId及客户端token，取消只处理本file前缀。
冻结noscope索引缺entity_id：同actor/token跨主体保持VALIDATION_FAILED且零凭据泄露；结构变更只提出证据交独立包。
备份公开端口若上游已落保留兼容；业务四桶不增第五枚举，COS真实适配补该既有端口而非改备份任务。
签名/地域/路径编码/超时/失败映射以实施时官方协议为准，来源和版本写README，不读取本机凭据发现链。

## 5. 不做什么

- 不改DDL、索引、约束、层白名单、route method/path/auth/idem/milestone或上传锁顺序。
- 不实现批次、媒体回查/审核/清扫、原片版本提交，不新增页面或扩大分类业务权限。
- 不操作真桶/CDN/STS策略，不读密钥或上传真实文件；不把fake分块当真实云已验。
- 不放宽原complete/promote错误/幂等/归属检查，不为可用假返回processed或versioning。

要落地的接口（4条）：

| operationId | schema/约束 |
| --- | --- |
| `m.analyticsEvent.batchCreate` | ClientEventProps严格属性白名单，eventId/ISO occurredAt/anonymousId；optional，按event_id去重 |
| `m.clientError.create` | raw application/x-sentry-envelope≤200KB，DSN白名单，optional/telemetry，202 data=null |
| `m.subscribeResult.create` | SubscribeResultBody；reportId/point/results，required subscribeReport:{reportId}，额度身份取当前session |
| `admin.clientError.create` | 与m错误形态一致，optional，不把登录页错误排除在外 |

表：wx_subscribe_quota/wx_template_slot、analytics_event/analytics_event_dedup/analytics_identity；错误信封不落业务表。
状态机/事件/timer：无新增业务状态机或出站事件；只登记analytics.dedup_purge、analytics.partitions、analytics_repartition CLI三项x01。
accept按quota_cap加一，ban清零/告警、filter告警、reject不改；未知tmpl忽略，重复report不重复增额度，开关关仍受理；数据身份不能由客户端指定。
十个客户端事件与契约ClientEventProps逐项一致，属性只允许枚举/uuid/字典编码；手机号、证照、token、邀请凭证、任意文本拒收，服务端19种事件不能由客户端伪装。
去重与新增事件同TX，按occurred_at分区；匿名关联首次绑定、匿名日上限200000默认按正式参数；分区预建/过期清理用既有受限数据库能力，不改结构/授权。
默认CLI只接一个YYYY-MM，按实际服务范围补缺分区/迁移合法行，重复无丢重；错误、超范围月份/未经授权连接拒绝；说明真实执行需业主按环境包授权。
错误转发队列200，满丢最新计数，外呼2秒、失败丢弃，10秒≥5失败熔断60秒；未配只脱敏日志，不输出DSN凭据/原信封。
两端beforeSend/request去敏复用已有封装；服务端再次验证项目/大小，不能任意URL转发形成SSRF；上报不受最低版本/协议同意阻断，正式限流仍保留。

- 不连接真实错误平台/模板后台或改账号设置，外部配置仍由业主处理。

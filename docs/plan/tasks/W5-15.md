## 1. 目标

沿已合M1–M4隔离支架串M5真实接口、后台处理及全不变量，交可重复演示与退出证据。
本包只有合流验证，不承接其他包遗漏的资金机制、授权算法、页面或Provider。
拥有接口：无；消费下表已合接口，全部归属仍在W5-01–09。

| 场景 | 实际入口与必须读回的事实 |
| --- | --- |
| 取消申请与执行 | `admin.order.cancelQuote`、`admin.order.cancelRequest.create`、`admin.cancelRequest.approve`、`admin.cancelRequest.execute`；六阶段积分去向与唯一账本事实 |
| 订单追溯 | `admin.order.activity.list`、`admin.orderItem.download.list`；原订单、工单、取消及下载事实一致 |
| 工单流转 | `admin.deliveryTicket.assignEditor`、`admin.deliveryTicket.rework`、`admin.deliveryTicket.reevaluate`；负责人、暂停与阶段真实读回 |
| 人工纠偏 | `admin.deliveryTicket.forceTransition`；现时权限、再次验证、版本和原因校验，不能绕开域守卫 |
| 样片修改 | `m.sample.requestChange`、`admin.sample.requestChange`；商家compose、经理compose/ad_content及既有可选feedbackTimeMs、截图，真实免费额度/修订/重传确认 |
| 广告全程 | `m.ad.quote`、`m.ad.create`、`m.ad.submit`、`m.ad.confirm`；正式创建、提交和确认 |
| 广告制作 | `admin.ad.adVersion.create`、`admin.adVersion.push`、`admin.adVersion.markSent`；真实版本/查看证据和权限 |
| 授权 | `m.licenseLetter.list`、`m.licenseLetter.get`、`m.licenseLetter.downloadUrls`；事实收敛、修订、PDF文件与签名状态真实 |
| 补发 | `admin.deliveryTicket.reissue.create`、`admin.reissue.publish`、`admin.reissue.cancel`；原交付、补发和使用期事实对应 |

不得只断言HTTP200或调用次数；读取余额、流水、审批、历史、审计、事件和真实文件引用。
六阶段取消、开工与取消竞争、暂停叠加、收敛乱序及跨节假日已有目标按所属包源码复用。
新增综合链补实际串联缺口；不重复完整历史性质矩阵，也不把小数据演示当容量基准。
每轮原90秒含初始化/主链/full/自然清理；十轮独立scope顺序运行，失败立即停止。
`demo:m5`默认新隔离库，在同库重放原意图证明业务零新增及完整字典保留。
生产、任意业务库和无归属资源拒绝；不能通过两次新建空库冒充幂等。
没有机构证书时只证明测试替身边界，不能声称数字签名或真实授权已送达。

## 5. 不做什么

不实现62条所属业务接口或另造新页；不改变metadata、冻结结构、锁序、账本只增与资金守卫。
不重写M3制作流水线或M6发布/ZIP/portal；取消/广告/授权状态由其公开服务生成。
不为了清零修改计数器、测试字符串扫描规则或过滤full检查项。
不读密钥、不连云、不真实收费/签发/发信，不自行打m5-done标签或部署。
不以Q9默认方案冒称用户已经确认，也不把旧样片桩的播放器误述当新增需求。

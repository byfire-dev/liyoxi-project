## 1. 目标

在W6-01–12实际交付后接通发布生命周期、只读portal、ZIP与三端页面的完整链，核原M6退出条件。
L/乙来自跨域并发、真实媒体和集成验证体量；不因此扩大业务实现或接管其它包writer。
当前冻结M6资源仍为55 API、12新页、9 x01、8桩；页面另含8旧页增量，不能只查新页。
55 API中53项按所属包实现；Q9排除的2条portal样片接口由W6-06协调正式冻结治理前置。
不能用恒拒绝handler、私自改计数或删除metadata凑清零；治理未actual合main时保留2项真实差额，不宣布M6退出。

| 集成段 | 必须读取的真实结果 |
| --- | --- |
| 使用期/顺延 | 止日只延不缩、旧代次不再触发、同目标仅一行未取消定时器 |
| 发布清单/分批上线 | 清单逐集完整、部分上线与回填、核验/撤销、原账号范围 |
| 巡检/下架 | 每周任务、跟进与异常/恢复；到期生成/作废、仍在线/核查/归档 |

| 签发/保存 | 每次现签有访问记录；真实保存后回报，重授/补发与旧包区分 |
| Q9/授权 | 样片无电脑入口/成功签发；广告只读；公开验真当前版与旧版脱敏 |

电脑扫码登录→整包下载→复制清单；小程序逐集存相册；回填链接→核验通过。
推进时钟到使用期结束→生成下架任务→核查归档，并核每周巡检生成。
自动化可以注入时钟；真实发布/试点限额、云打包和真机相册结论独立登记。
复用已合public testing、transport、clock和自然清理；不直写业务终态或借未合分支。

## 1. 目标

按正式原型落地五个后台页面，调用W3-09/10/11真实接口，列表/计数/校验/价格/动作由服务端提供。
既有admin shell/权限菜单/UploadField/播放/日期/表格机制复用；短剧编辑里的原片批次是增量，无第六新页。
actual drama/ops模块路由清单目前为空，五页须真实注册；已有成片上传页增量属于W3-02，不能重复算页面。

要落地的页面（5条）：

| page key | path / 可执行行为 |
| --- | --- |
| `drama.list` | `/dramas`；筛选/页签/服务端summary/actions、选行到编辑，真实上下架确认 |
| `drama.edit` | `/dramas/$id`；基础/商业/版权/角色/剧集/许可/预告片，原片批次dialog不增页 |
| `billing.pricing` | `/billing/pricing`；单剧当前/待生效价/记录、调价与撤销，模板只读 |
| `ops.home` | `/ops/home`；Banner CRUD/顺序/上限、推荐草稿保存→发布与历史 |
| `ops.mall` | `/ops/mall`；分类/热词/筛选/排序权重草稿→发布与失效引用提示 |

HTTP/x01/timer/留桩：无新增；页面仅消费正式a04/a09/W3-02接口，灰/隐藏动作来自权限与actions，不从角色名字推断。
列表统计只用summary，所有筛选/选中tab入validateSearch/URL，切页保留返回状态，字面路径与剧目id参数不冲突。
编辑表单每资源各自lockVersion，版权当前锁不混剧目锁；409保留草稿并提示刷新/合并，不偷偷读取新版本重发覆盖。
上架dialog展示同份L1–L14阻断/警告及实际missingEpisodes/在途批次，确认时真实required API再校验，不能用按钮禁用替代服务守卫。
许可复核用明确确认动作/note与正式单向接口；版权修订展示旧止日/新值/依据，shorten拒绝可见，initial不是可编辑选项。
原片上传复用W3-02四态匹配/人工逐集/完整覆盖/AI声明/断点恢复，不造ready，cancel/commit只在正式batch动作允许时给出。
预告片真实processing/ready/failed、重试与旧target保护；播放器复用公共签名/到期刷新和正式开关，不暴露原片/public URL。
调价confirm.currentPoints来自刚展示服务器P，custom/template字段成对、未来日期不早于明日，记录/撤销按actions；已冻订单价不前端推导。
Banner未结束排序集合含停用行，拖动后调用batchReorder；活跃上限由summary.maxActive提供，409保持真实列表重载后再操作。
站点分类all固定、热词/分档/权重服务端schema错误定位fieldErrors.path；invalidRefs标红，affectedBanners只提示不误阻发布。
保存→发布各用独立幂等键，publish传刚返回draft.lockVersion与页面baseRevNo；第二步失败显示草稿已存，可单独重试发布。
历史回滚读历史content→新草稿→新发布版，不直接改历史rev；字段引用选择器用实际字典/剧目数据，无硬编码真实对象id。
权限矩阵覆盖v/e/版权修订/调价独立权限；待生效/归档/未配媒体显示实际状态，tooltip/empty/error不吞领域错误。

## 5. 不做什么

- 不新增backend/HTTP/x01/页面key，不改DDL/metadata/层级、公共表格/上传/播放器/权限机制。
- 不写等级模板价/计费参数（W4-17 UI）、V1.1公告CMS，不在前端复制上下架/定价/引用守卫。
- 不新增颜色变量/主题副本/硬编码hex，不把静态prototype数据或内存mock当live完成。
- 不对真实版权/剧目/积分价/站点操作，不变更外部配置/存储/通知或部署。

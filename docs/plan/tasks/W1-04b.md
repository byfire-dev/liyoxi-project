## 1. 目标

W1-03 交了服务与契约、W1-04 交了鉴权链，本包把两者接起来：7 条接口在完整的中间件链下可用，被 CI 判为已落地。做完后 m01 在 M1 的 9 条、m02 在 M1 的 3 条全部落地，小程序的登录、重新同意、建主体、门店切换有接口可调（W1-05、W1-09）。

本包落地 7 条：

| operationId | 方法 路径 | 鉴权 | 店员视图 | 幂等 |
| --- | --- | --- | --- | --- |
| `m.agreementConsent.create` | `POST /m/agreement-consents` | `user` | `same` | natural（`uq_agreement_consent_no_biz`） |
| `m.agreementConsent.list` | `GET /m/agreement-consents` | `member` | `trimmed` | none |
| `m.agreementConsent.summary` | `GET /m/agreement-consents/summary` | `member`；`contract.read` | `none` | none |
| `m.entity.create` | `POST /m/entities` | `user` | `same` | required |
| `m.store.list` | `GET /m/stores` | `user` | `trimmed` | none |
| `m.me.currentStore.replace` | `PUT /m/me/current-store` | `member`；`me.*` | `same` | required |
| `m.dictItem.list` | `GET /m/dict-items` | `public` | `same` | none |

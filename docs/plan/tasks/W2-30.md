## 1. 目标

添加 M2 一份完整接口级端到端脚本、`pnpm demo:m2` 与演示手册，核 M2 代码侧退出并移交真机/预发未验。
沿 W1-21/W0-30 实际已交的执行/造数/时钟注入机制，只加 M2 场景，不另造第二套 E2E 框架。

| 主链 | 真实 operationId / 可观察结果 |
| --- | --- |
| 登录 / 个人协议 | `m.session.phoneLogin`、`m.agreement.list`、`m.agreementConsent.create`；替身微信、当前版本与本人会话 |
| 多门店 / 邀请 | `m.store.create`、`m.invitation.create`、`m.invitation.lookup`、`m.invitation.accept`、`m.member.list`；真实 quota/seat 与成员摘要 |
| 资质多轮 | `m.storeProfile.qualification.update`、`m.storeProfile.qualification.submit`、`m.qualificationSubmission.list`、`admin.qualificationSubmission.approve`、`admin.qualificationSubmission.reject`；驳回→重提→通过与历史 |
| 个人安全 | `m.smsCode.create`、`m.me.changePhone`、`m.me.wechatIdentity.list`、`m.me.wechatIdentity.delete`；当前会话、绑定及受控错误 |
| 人工账号变更 | `admin.accountChangeRequest.create`、`admin.accountChangeRequest.approve`、`admin.accountChangeRequest.get`；老板更换后唯一 owner、旧授权失效与审计 |
| 员工禁用 / 移交 | `admin.staff.disable` 与实际移交公口；在办来源、池/轮询、会话吊销同事务 |
| 配置即时生效 | `admin.featureFlag.update` 与实际配置公口；权限/actions 重新读取，不硬编码引导值 |
| 通知 / 埋点 | `m.message.list`、`m.message.read`、`m.message.batchRead`、`m.subscribeResult.create`、`m.analyticsEvent.batchCreate`；真实未读/去重与新结果 |
| 框架 / 运维 | `admin.timer.list`、`admin.timer.reschedule`、`admin.timer.cancel`、`admin.outboxDelivery.list`、`admin.outboxEvent.retry`、`admin.webhookEvent.list`、`admin.webhookEvent.retry`；投递、到期、重投与告警落库 |
| 注销 | `m.me.deletion.create`；六类阻断与零阻断联动，成功后账号/关系/会话真实结果 |

接口以 actual routes 的完整 operationId 为准；开工复核 W2-xx 已合测试输入，不用草案参数代替真实 DTO。
复用 W1-21 已合 M1 主链覆盖订购→方案/样片/成片→上线，再叠本表 M2 生命周期；付费主体注销应受阻，无业务虚构账号才验证成功注销。
本包不拥有上述接口、表、状态机、事件、定时器；每段执行后读真实已提交状态/历史/审计，不直接修改业务状态。
出站与 timer 在测试装配排空；注入 clock 推进邀请期限/生效边界，不真实 sleep、不运行外部 Provider。
退出基准按正式 map：M2 新归属 122 API、20 登记页、29 x01、19 桩；开工 actual 若变动须按唯一源重数并记依据，不能硬凑数字。
M2 pending 接口、未实现页、应回补桩和缺处理器/测试的 x01 均清零；M3/M4/M5/M7 留桩如实保留。
退出只 require M0/M1/M2，不能要求全局 pending/未实现页/未回补桩为 0。
W1-21 actual 后的新三桩按实际台账保留：m3-admin-output-batch-upload→W3-02/后台成片增量；m4-admin-order-payment-tab→W4-17；m6-admin-plan-channel-selection→M6 后继。
完整店员与后台权限矩阵沿各包已交目标，不由一条主链替代全部角色/字段/并发验收。

## 5. 不做什么

不新增服务 API/页面/状态机，不在合流包修业务算法、放宽某段守卫或造 DB 状态使链通过。
不把主链替身成功当真实微信/短信/媒体/预发通过，不实际部署、SSH、上传、提审或使用密钥。
不触 M3–M7 路由/页/桩归属，不实现客服/portal/支付/正式文本来提前清后续计数。
不删旧 clerk/权限/性质用例、关不变量、不提高 baseline/预算/required 名单。
不由作者打 m2-done/weapp-v 标签或合并；调度在全部条件满足后按当前规范处理。

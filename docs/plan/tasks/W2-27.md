## 1. 目标

- 预发出了事有人知道、有地方查：容器日志留得住又不撑爆 40GB 的盘；不登录服务器也能按请求编号查到日志、算出 5xx 率与 P95；三端的错误进错误上报的上游；探针报出的告警发到业主的群里。
- 本包做的是“接线”：配置、节点步骤、演练办法与运行手册。告警的判断与发送、错误上报的转发接口是代码包的事，不在本包。
- 使用方：M2 的预发演示（制造积压能收到告警、清空 Redis 后周期任务照常触发）；之后每个里程碑的预发联调。

## 5. 不做什么

- 不写告警的判断与发送、探针规则、`alert_event` 的读写（探针与告警包）；不写错误上报的转发接口、三端 SDK 的初始化与清洗规则（代码包）。缺什么配置项由那两包加进 `loadEnv`，本包只给值与文件。
- 不建云日志、不接日志平台的看板与告警（随生产）；日志保留达不到 180 天，预发阶段接受（ADR-041“代价”第 9 项）。
- 不登录服务器；群机器人地址、上游地址、值班人手机号、源码映射令牌的值一概不经手，仓库里只出现它们的文件名与密文名。
- 不改 `apps/`、`packages/`；不做后台“系统健康”页（M7）。
- `redis-flush` 只给演练用：只认本项目 Compose 里的 `lyx-redis`，冻结时拒绝，不做成发布流程的一步。

## 7. 验收

都在本机与 CI 上验。预发上的接通写在第 8 节。

| # | 验收项 | 命令 | 判据 |
| --- | --- | --- | --- |
| 1 | 5xx 率与 P95 | `pnpm test`（`infra/deploy/test/log-stats.test.ts`）；演练里跑一次 `log-stats` | 对夹具日志算出的 5xx 率与 P95 与手算一致；坏行跳过并计数；演练环境里能出数 |
| 2 | 轮转 | `pnpm stg:rehearse`（读 `docker inspect`） | 六个容器的日志驱动都是 `json-file`，各有大小与个数上限；合计上限写在 `node.yml` 的注释里，不超过 1GB |
| 3 | 受限查日志 | `pnpm test`（`node-step.test.ts`） | `logs` 只接受白名单里的服务名与 UUID 形态的请求编号，别的参数一律拒绝；输出行数有上限 |
| 4 | 清空 Redis 的演练步骤 | `pnpm stg:rehearse -- --redis-flush` | 容器名或 Compose 项目对不上即拒绝；冻结变量为真时拒绝；清空后 worker 不重启，租约照常续，两分钟内出站与定时器恢复处理（`/health` 的 `worker` 一项保持正常） |
| 5 | 告警发得出去 | `pnpm stg:rehearse -- --alerts` | 把群机器人地址指到本机的假接收端：停掉 worker 让出站积压，假接收端收到一条告警；恢复后收到“已恢复”；地址没配时告警照常落库、进程不报错 |
| 6 | 错误报得上去 | `pnpm stg:rehearse -- --errors` | 把上游指到假接收端：经 gateway 向商家端与后台的转发接口各发一条信封，都回 202，假接收端各收到一条；上游没配时 `check-env` 仍通过，启动日志 `providers ready` 一行标出未配置 |
| 7 | 源码映射 | `pnpm test`（工作流清单用例） | 没有令牌时这一步跳过、工作流不红；步骤里不打印令牌 |
| 8 | 运行手册 | 人工对表 | 第 4 节点到的九条规则各有“现象、先看、判断、处置、不要做、升级、事后”七栏；用到的节点步骤都是已有的 |
| 9 | 已有门禁 | `pnpm lint && pnpm format:check && pnpm typecheck && pnpm test && node infra/ci/classify-gate-changes.mjs --base origin/main` | 退出码 0；门禁改动只有只增类 |

第 5、6 条要等第 3 节那两个代码包；它们没合并时按第 9 节先交 a。

## 9. 交付与收尾

- 按两步交，不改编号：a = 日志轮转、`logs` 与 `log-stats`、`redis-flush`、核对表、运行手册里只与日志和 Redis 有关的行（验收 1–4、8 的一部分），只等 W2-26；b = 告警与错误上报的接线、演练、源码映射（验收 5–7），等第 3 节的两个代码包。

## 10. 实现要点与默认（本任务书定）

| # | 要定的事 | 默认 |
| --- | --- | --- |
| 1 | 轮转的值 | api、worker、gateway 各 20MB × 5，库、Redis、mediatool 各 10MB × 3，合计上限约 390MB；`node-init.sh` 的磁盘告警线 80% 不变 |

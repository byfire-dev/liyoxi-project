# W2-12 协议版本、同意记录与文书保留清理

| 项 | 内容 |
| --- | --- |
| 组 / 里程碑 | G2-B / M2 |
| 规模 / 级别 | L / 乙 |
| 交付边界 | 8 条接口；0 页；2 个 x01 cron；回补 2 项桩 |
| 分支建议 | `feat/W2-12-docs-versions`，从实际 main 开工 |

## 1. 目标

完成六份 V1.0 协议的草稿、安排生效、撤回、同意记录后台读取及协议 PDF 现签；补文书定时清理/证据摘要。
保留 M1 的 `assertConsents` 只增记录、当前版本按时间实时解析和合同证据快照，不重写交易同意顺序。
要落地的接口（本包唯一新增归属）：

| operationId | 结构与业务边界 |
| --- | --- |
| `admin.agreement.agreementVersion.create` | 本协议新草稿；一个有效草稿约束 |
| `admin.agreement.get` | `AgreementDetail`；版本、当前时间 phase、actions |
| `admin.agreement.list` | `AdminAgreementListQuery` / `AgreementListItem` |
| `admin.agreementConsent.get` | `AgreementConsentDetail`；证据与经办人脱敏 |
| `admin.agreementConsent.list` | `AgreementConsentItem`；筛选、分页与计数 |
| `admin.agreementVersion.schedule` | lockVersion、文件齐备、法务审定、时间/公告期与权限 |
| `admin.agreementVersion.update` | 草稿字段与 source/pdf 文件替换，保留非草稿不可改 |
| `admin.agreementVersion.withdraw` | 无同意且距生效 >10 分钟；原版 withdrawn，新草稿另 id |

表：`agreement`、`agreement_version`、只增 `agreement_consent`；`site_notice` 由现有 L0 config 公口写，文件引用走本域端口。
状态机：agreement_version draft→pending→active→superseded、pending→withdrawn；所有迁移用 flow 与历史。
事件按 x01：版本安排/生效/撤回及 `site_notice.announced/withdrawn`，不虚构一次 GET 生效事件。
x01 本包唯一实装 `docs.sweep`（每 5 分钟）和 `evidence.consent_digest`（北京时间每日 00:40）。
`docs.sweep` 只补本里程碑协议/保留工作；已有任务的 M5 授权书渲染等分支准确留桩，不抢接口归属。
回补 `m2-docs-agreement-pdf-url.md`；协议 PDF 经私有签名端口，返回真实 expiresAt，不再 url 空串。
承接 `m2-docs-agreement-placeholder-text.md`：实现正文/文件可编辑与法务状态；E8 未提供正文时保留诚实占位，不虚报法务已交。
M1 `config/notices.ts` 的 `createNotices` 只有 announce；本包补 `notices.withdraw` 与撤回协议同事务，保留 announcement 行历史。

## 5. 不做什么

不增加 partner 第七协议；它属于 V1.1 迁移，不改 V1.0 六份播种与版本约束。
不把 PDF 缺配置写成假 URL/假 expiresAt，不以 GET 翻簿记状态，不修改已经签署的同意/证据快照。
不以 status=active 取当前版本；到点即按 effectiveAt 解析，五分钟 sweep 的延迟不能影响报价/提交一致性。
不做 M5 授权书初渲染/改版、M4 合同业务标题、匿名验真、真实正文代法务审定。
不改变 legal_doc 分类授权，不开放任意文件 ID；不存在/外scope 不可枚举，引用归属锁后再验。
不改 docs→media 白名单、schema/constraints、锁表、事务/签名框架；改公共机制需独立窄 PR。
不放松旧同意时间顺序、只增触发器、权限矩阵或不变量全量检查。

## 6. 允许新增的依赖

无新依赖。docs 仅用 L0 kernel/config/events/audit/flow 等已有公开口；跨 L1 media 通过 pure port。
source/pdf 文件角色与 ref_type 用实际 FILE_REF_TYPES；草稿换文件解除旧引用，离开草稿永久保留。
摘要 hash 复用现有 Node 加密能力；桶写入仅经已合 Provider，缺能力先小 companion，不能根依赖升级。

## 8. 需要业主做的事

开工、合并前无；E8 六份协议正式正文及法务审定后续提供，不由开发者默认勾选。

## 9. 交付与默认

乙类八接口；协议状态/公告/同意的一条生命周期单 PR，涉及公共签名或结构机制的改动单独拆。
状态分开写代码回补与 E8 外部未办；不能把 placeholder 桩“已回补”当正式法律正文已到。
当前版本唯一解析函数被 merchant/admin/pending-consent/交易引用复用，sweep 只簿记；注入 clock 保留。
同意记录按调用方真实动作时间追加，不预锁计费账户来伪造同一时刻；交易消费原公开接口顺序。
版本撤回保留旧 source/pdf 与 site_notice_id，新草稿另 id；已有草稿时 newDraft=null，严格按 a09 响应。
cron 引用的文书保留分支据 M2 actual 能力补齐，未知外部能力受控告警并注明，不偷实现 M5/M7。
作者本地正常提交、五节正文交调度；一轮独立复审，完整 CI 与窄阻断闭环，不追加正式二审。

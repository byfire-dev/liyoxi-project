## 1. 目标

接腾讯云录音文件识别与境内OpenAI兼容主备端点，完成ASR、vision、doc_extract、digest驱动。
本包唯一新增归属HTTP/x01都是 `hooks.asr.mediaJob.wake`；0页/0留桩，不重复接media_job执行循环。
实际AsrProvider只有transcribe({url})，LlmProvider只有tagAsset/extractKeyPoints；不能假称已有异步提交回查或doc_extract能力。
必要窄Provider扩展需保留所有旧方法/假实现/未配置实现与状态；新输入/输出纯类型明示新增。

| operationId | schema / 行为 |
| --- | --- |
| `hooks.asr.mediaJob.wake` | 新增AsrWakeParams/Query/Body schema，响应复用HookAck；sig校验、可信来源去重，只唤醒实际mediaJob |

回调按h01§3.8：HMAC-SHA256/asr密钥/base64url；任务UUID与sig验证，body只读官方任务号，natural键mediaJobId:任务号。
仅submitted把next_run_at置now，其他记ignored；未配404 WEBHOOK_SOURCE_DISABLED，结果仅以Provider回查为准，原文/URL不存。

| 步骤 | 真输入与结果事实 |
| --- | --- |
| transcript | 本域已授权文件的短期读URL；腾讯录音任务ID、回查文本/分句/时长，缺字段不造默认 |
| vision | 图片或可信视频截帧；只内容描述/人脸提示/内容标签，人工决定用途/时效/可用性 |
| doc_extract | 隔离容器PDF/Word文本抽取；表格不抽，doc_text页数/字数按真实输出 |
| digest | 实际可用转写/图像描述/文本；要点与标签受schema限制，不写模型原始敏感响应 |

逐file/kind/prompt_version写store_asset_insight，成功复用只同主体、同指纹、同提示版本。
media_job已由W3-03拥有；复用租约、produceId/provenance、崩溃回查/幂等，不造第二队列。
任一步未配/失败只标对应步骤失败/跳过，isInsightPartial真实，素材仍可入库人工复核。
主端点失败才按明确策略用备端点；禁止境外线路、无界重试、任务持锁等待模型。
敏感文本/URL不落日志或outbox；存业务洞察并保留prompt/provenance必要证据。
仅沿既有asset.processed/review_needed事件由W3-14推进，不重复登记/假同步通知。

## 5. 不做什么

- 不做实时录音转写、境外模型、自由代理URL、模型评测平台或AIGC制作。
- 不自动开后付费能力，不提交凭据，不在事务内HTTP或下载任意公网地址。
- 不改签名/锁序/DDL/队列算法，不强行把现同步Provider假成异步已实装。
- 不让模型确认肖像授权，不覆盖人工标签，不把跳过算成功、不吞transport故障。
- 不改x01名称/里程碑，不把回调载荷当已验证洞察，不新增后台页面。

## 1. 目标

在现有合同页增加定制内容授权书列表/计数、详情与PDF查看；保留已签协议原功能。
0新增API/页面/x01，不生成PDF、伪签章或改授权法律范围。

| 页面key / route | 本包边界 |
| --- | --- |
| `sub/billing/contracts/index` | 已有页新增授权书区、同页详情/预览，不添授权书独立页 |
| 现有合同文档薄调用 | PDF每次现签并受控打开，旧协议按同意过的版本查看 |

| 消费operationId（不拥有后端接口） | 行为 |
| --- | --- |
| `m.licenseLetter.list` | 按当前门店/可选orderId查询，剧目×发布账号逐份列出 |
| `m.licenseLetter.summary` | 与列表同scope的真实数量，不用当前分页长度估总数 |
| `m.licenseLetter.get` | 授权方/被授权方、许可、账号、期限、版次与验真码 |
| `m.licenseLetter.downloadUrls` | 现签5分钟PDF地址，保持服务端访问审计 |
| `m.agreementConsent.list`、`m.agreementConsent.summary` | 原已签协议、老板/店员裁剪，原summary禁用分支不改变 |
| `m.agreementVersion.get` | 原所同意历史版本/PDF，不能改用当前新正文 |

请求/响应从`@liyoxi/contract/types/merchant`的operations推导，params/query/文件结果依W5-07实际schema。
授权状态待生效/生效中/失效与修订版次来自服务端，不在前端按本地日期推导。
同剧不同发布账号不合并成一份；旧版/修订原因保留，不能用“已失效”删除历史证据。
老板受contract.read/当前门店守卫，店员不发授权书受限查询；隐藏区域不能代替服务端鉴权。
请求失败、无授权、生成中、PDF不可用与真正失效分开，错误/等待不伪造空列表。
链接只从真实GET结果取业务ID，现签地址不落持久缓存、不拼桶路径或回显凭据。
换门店、退出、卸载或换选中授权时，迟到GET/签名/下载不得覆盖新范围或打开旧文件。
法律正文/签名真假以W5-07实际输出与外部结论为准，不写“以双方签章版为准”。
授权书只是合同页增量，订单详情的售后/授权导航分别由W5-10、W5-13承接。

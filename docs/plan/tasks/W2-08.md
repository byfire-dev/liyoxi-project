## 1. 目标

落地 SysLogs 操作日志主从页，提供真实过滤、游标分页、脱敏差异与关联业务跳转；超级管理员可在同页查看 access 流的 PII/敏感签发留痕。
PII 访问查询是查询访问记录，不在日志页额外增加明文浏览器或字段“查看”眼睛；明文用例由 W2-04 与对应业务页接入。
本包唯一新页面 system.logs；不创建独立 PII 页、导出抽屉或新操作接口。

页面：system.logs，URL `/sys/logs`，画板 SysLogs，master-detail，M2、inMenu=true；唯一新增页。
接口：只消费 admin.auditLog.list/get；PII 用例验证使用已落地 admin.piiReveal.create 产生真实 access 记录，不新增接口/schema。
表、状态机、出站事件、timer：均无生产写入；浏览器查询不能直接 DB、写 audit 行或生成日志编号。
默认 stream=ops；system≥v 可进入。access 只给超级管理员，非超管不渲染切换入口，直接 URL/API 403/404 仍由后端控制。
不把 activity 流混入该页；门店活动流属于对应商家详情。category 取正式编码/展示映射，不自己制造业务类别或未来枚举。
过滤按 AuditLogListQuery：category 多值、actorType/actorId、targetType 与 targetId/targetKey 二选一、entityId/storeId、q、createdFrom/To、cursor/limit。
q 为 RZ 编号时精确查询，否则按标题包含；“近 7 天/近 30 天/全部”转成 Asia/Shanghai 日期，两端含，URL 非法组合由 validateSearch 拒绝/规范化。
游标按后端 created_at DESC、seq DESC；保留 totalApprox 的“共 N 条”口径，不能把近似总数当精确页数；筛选/stream 变化清 cursor 和旧详情。
详情显示 actor/角色/client、目标/门店/主体、时间、脱敏 before/after/meta、登录方式/IP 与 link；system actor 的 null 值按正式 DTO 展示。
使用 W2-02 已有 mask/比对构件，未知嵌套对象按安全展示规则裁剪；不通过 tooltip、复制、title、JSON 原文或 DOM 隐藏节点泄漏敏感值。
关联页面只读后端 link，结合已落地路由与权限决定可点；无 link/未来页显示普通标签，不捏造 URL 或开放外链输入。
PII 留痕显示员工、目标、field/action、purpose/note、时间与审计编号，不显示被查看值；操作日志详情不能再次解密其他字段。
列表/详情 GET 无业务写入或 access 审计副作用；测试通过实际 PII POST 造访问记录，再用日志页查询，不能靠手写“已访问”终态证明链路。
日期使用 W2-02 已有构件；keyboard Tab 进入/离开、Esc 收起需在实际浏览器验证。发现共享缺陷交独立构件 PR，不绕焦点陷阱。
请求沿既有客户端 401/403/404/429 处理，失效清空已选详情；加载/筛选空态/错误/无权限分开，不保留上个用户详情。

## 5. 不做什么

- 不新增 PII 明文页、眼睛图标或自由 table/field 查询，不把 access 明文值加入日志 DTO/URL/本地存储/埋点。
- 不实现导出接口/任务/记录抽屉；正式 exportJob 尚未 actual 时不渲染“假导出”按钮，交 W2-31 拆包。
- 不改后端 audit/security/authz/API/contract、现有权限、限流或数据范围；前端禁用不是服务端授权替代。
- 不改 AppShell/共享骨架/DateRange/mask/主题，禁止页面私拷通用构件。
- 不改 live.mjs、Playwright 配置/起栈；不使用浏览器 mock 截图作为真实链证据，不接生产数据。

## 6. 允许新增的依赖

无。使用现有客户端、Router、React Query、日期/主从/比对构件及 Playwright。

## 1. 目标

- 本机一条命令起一套“像预发一样”的环境：gateway（nginx，听 8080）→ api，worker 与无网络的 mediatool 共用一个卷，库、Redis、对象存储用已有的那份共享实例。后台与下载页由 gateway 给出，小程序开发者工具与开发版真机连它。
- 三个镜像有了第一版：`liyoxi/server`（api、worker、迁移、命令行同一个镜像）、`liyoxi/gateway`、`liyoxi/mediatool`。预发照用这三个镜像，不另写。
- 使用方：W1-21（演示点 A、B 在这套环境上手验）；G2-D 的环境包 W2-25（预发的六个容器由这三个镜像起）、W2-26、W2-28。

## 5. 不做什么

- 不做第四个镜像 `weapp-uploader`、节点上的 Compose（`node.yml`）、systemd、密钥文件、推镜像仓库：W2-25。不做发布编排：W2-26。
- 不改 `apps/api`、`apps/worker` 的业务与装配代码，不加环境变量：`loadEnv` 当时有哪些键，Compose 就给哪些值。缺 `check-env` 这类入口时用 `worker --check` 顶，不在本包补。
- 不把 mediatool 的调用端挂到 `media` 接口（G3-A）；冒烟只验容器健康与套接字连得上。
- 不动 `infra/ci/layers.json`、`ci.yml` 里已有的步骤、`.dependency-cruiser.cjs`；不把本包的工作流加进 `required`。
- 不往 `liyoxi`、`lyx_schema_check`、`lyx_migrate_check` 三个库写数据；不 `infra:down`、不删别人的库与卷。
- 镜像里不放任何密钥、`.env`；Compose 里出现的口令只有 `local.yml` 那组公开的开发值。

## 7. 验收

证据是 `stack-smoke.yml` 在 PR 上的运行。它不在 `required` 里，PR 描述里单独给链接。

| # | 验收项 | 命令 | 判据 |
| --- | --- | --- | --- |
| 1 | 三个镜像能构建 | `pnpm stack:build` | 得到 `liyoxi/server:local`、`liyoxi/gateway:local`、`liyoxi/mediatool:local`；构建不读 `.env`，构建上下文里没有 `.git`、`node_modules`、`docs/` |
| 2 | server 镜像的内容 | `node infra/stack/smoke.mjs --image-only` | 镜像内 `pg_dump --version` 主版本 = `local.yml` 里 PostgreSQL 的主版本（17）；`age --version` 可跑；三个 TTF 的 sha256 与字体目录 README 的表一致；`ffmpeg` 不存在；运行用户不是 root；`node apps/worker/dist/index.js --check` 在给全变量时以 0 退出、缺必填变量时非 0 |
| 3 | 一条命令起整套 | `pnpm stack:up` | 依赖没起会先起（等同 `pnpm infra:up`）；建库 `lyx_stack`、跑完全部迁移与种子；四个容器都健康才返回；再跑一遍不报错、不重复播种 |
| 4 | 冒烟 | `pnpm stack:smoke` | 经 gateway：`api.localhost:8080` 的 `/healthz`、`/readyz` 回 200，`/health` 的响应里 `worker` 一项在 worker 持有租约后不再是 `down`（探针循环 M2 才有，整体状态码照 W0-22 的口径，冒烟不断言它）；`admin.localhost:8080/` 给出后台入口页，页里引用的每个 `/assets/` 文件 200 且带长缓存头，入口页不缓存；`portal.localhost:8080/` 同理；`admin.localhost:8080/api/v1/m/…` 得 404（域名隔离）；超过 2MB 的请求体得 413；从 worker 容器经共享卷里的套接字问 mediatool 的 `/healthz` 得 200 |
| 5 | 容器约束 | 同上（`smoke.mjs` 里读 `docker inspect`） | mediatool 的十三项与 `compose.verify.yml` 一致（无网络、根只读、非 root、去掉全部能力、`no-new-privileges`、进程数、内存、CPU、`/tmp` 内存盘、只挂 `/work`、不带环境变量）；api、worker、gateway 非 root、根只读；只有 gateway 发布端口，且只绑回环地址 |
| 6 | 收场 | `pnpm stack:down` | 只停本包的四个容器，卷与 `lyx_stack` 库保留；依赖的三个容器不动。加 `--reset` 时删 `lyx_stack` 库与 `/work` 卷，别的库一个不动 |
| 7 | 脚本的用例 | `pnpm test`（`infra` 项目） | 起停脚本对“依赖没起”“端口被占”“库已存在”三种情形的行为有用例（桩掉 `docker` 命令）；库名不以 `lyx_` 开头时 `--reset` 拒绝执行 |
| 8 | 已有门禁 | `pnpm lint && pnpm format:check && pnpm typecheck && pnpm test && node infra/ci/classify-gate-changes.mjs --base origin/main` | 退出码 0；门禁改动只有只增类（新工作流、四个根脚本） |

## 9. 交付与收尾

- 一个工作包一个 PR。提交顺序：server 镜像 → gateway 镜像与模板 → `stack.yml` 与起停脚本 → 冒烟与工作流 → 文档与状态文件。
- 体量：Dockerfile 与模板约 250 行，脚本约 350 行，不涉及接口与页面，不拆。
- 同 PR 把 `docs/plan/status/W1-22.md` 写成“完成”；不推送、不开 PR、不合并。
- 第 10 节的默认有哪条没照做，在状态文件“偏差”里记一句。

## 10. 实现要点与默认（本任务书定）

| # | 要定的事 | 默认 |
| --- | --- | --- |
| 1 | Compose 怎么与共享实例相处 | 另一个项目 `liyoxi-stack`，接进 `liyoxi` 项目的网络（外部网络），按容器名连 `lyx-postgres`、`lyx-redis`、`lyx-minio`。容器名 `lyx-gateway`、`lyx-api`、`lyx-worker`、`lyx-mediatool`，与预发同名。整套只起一份，多个 worktree 共用 |
| 2 | 用哪个库 | `lyx_stack`，由 `stack:up` 建。`liyoxi` 留给手工开发；整套环境要能删库重来（演示重放），库名带 `lyx_` 前缀才许删。Redis 键前缀照 `APP_ENV=local` 的缺省 |
| 3 | 迁移与种子谁跑 | `stack:up` 用 server 镜像起一次性容器：`prisma migrate deploy`，再跑种子命令。不在宿主机上跑，这样顺带验了镜像里的迁移入口 |
| 4 | server 镜像怎么构建 | 多阶段：构建阶段 `pnpm install --frozen-lockfile` 后跑 `pnpm db:generate` 与两个应用的 `build`；运行阶段只拷产物、生产依赖、`packages/db/prisma`、字体。构建号经 `LYX_BUILD` 传入（W0-22 的写法） |
| 5 | 字体目录的变量名 | `LYX_PDF_FONT_DIR=/app/fonts`，写在镜像的 `ENV` 里（与 `spikes/license-pdf` 同名；G5-B 接 `loadEnv` 时沿用） |
| 6 | 本地的域名 | `api.localhost`、`admin.localhost`、`portal.localhost`（浏览器把 `*.localhost` 解析到本机）。模板里域名是变量，预发填 `*.stg.liyoxi.timavia.com` |
| 7 | 真机走局域网 | 缺省只绑回环。`pnpm stack:up --lan` 时 gateway 改绑全部网卡，并多开一个端口把请求原样转给 MinIO（`Host` 不改写，预签名才验得过）；按 IP 进来的请求在本地模板里走一个缺省站点，全部转 api。README 写明这组口令是公开的开发值，只在可信的局域网里开。演示手册怎么用它归 W1-21 |
| 8 | mediatool 的内存 | 照 X-02 写 `mem_limit: 1g`，另写 `memswap_limit: 1g`（X-02 复审备注 9：不写时宿主机有交换区会用到 2GB）。预发调低归 W2-25 |
| 9 | 工作流何时跑 | `stack-smoke.yml`：PR 改到 `infra/docker/**`、`infra/compose/**`、`infra/stack/**`、`apps/api/**`、`apps/worker/**`、`packages/db/prisma/**` 时跑；main 上每次合并后跑。超时 15 分钟。不进 `required`（PR 必过检查合计 ≤15 分钟） |
| 10 | 可信代理 | 模板变量 `TRUSTED_PROXY_CIDRS`；本地填 Compose 网络的网段。`set_real_ip_from` 与覆盖写 `X-Forwarded-For` 照 D7 第 7.2 节 |

## 1. 目标

- 每个主体的积分有一套只增流水的账本：发放、加购入账、冻结、扣减、释放、退回、清零、调整都经同一个骨架（账户锁 → 账本时钟 → `advance` → 操作键去重 → 桶移动 → 自检），重放无副作用，并发不超扣。
- 到点的事（月度发放、期末清零、预约周期接续、过期停用）只在 `advance` 里发生：写操作开头调一次，worker 每分钟兜底。
- 使用方：W1-11a（履约）、W1-13 与 W1-04 的“我的”页（余额与权益的读）、W1-15（冻结）、W1-17（扣减）；M4、M5 的续费、退款、取消在它上面加操作，不改骨架。

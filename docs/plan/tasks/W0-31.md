## 9. 交付与收尾

- 一个 PR。提交分几个：本任务书；任务书按组；台账与计划变更；状态文件。
- PR 描述按 `.github/pull_request_template.md`，开头列出：依赖或级别与计划原文不同的包、环境包的 5 个编号、“M1 的包依赖齐了即可开工”这条计划变更。
- 同 PR 把 `docs/plan/status/W0-31.md` 写成“完成”。
- 不推送、不开 PR、不合并。

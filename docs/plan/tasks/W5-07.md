## 1. 目标

将 W5-06 的不可变版次快照渲染成可追溯 PDF，提供真实授权书查询、人工重出和敏感下载。
内容指纹、最终 PDF 哈希与签署方式各自留证；替身图片章不得冒充机构数字证书。

拥有接口（8条，权限、能力、幂等、路径与 M5 归属沿 actual contract）：

| operationId | 方法与实际路径 | 请求 → 响应结构 |
| --- | --- | --- |
| `m.licenseLetter.list` | GET `/m/license-letters` | orderId/storeId/includeVoided/cursor/limit → CursorPage&lt;LicenseLetterCard&gt; |
| `m.licenseLetter.get` | GET `/m/license-letters/{licenseLetterId}` | 当前主体信件id → LicenseLetterDetail |
| `m.licenseLetter.summary` | GET `/m/license-letters/summary` | 同列表去分页 → LicenseLetterSummary |
| `m.licenseLetter.downloadUrls` | POST `/m/license-letters/{licenseLetterId}/download-urls` | LicenseLetterDownloadBody → LicenseLetterDownloadUrl |
| `admin.orderItem.licenseLetter.list` | GET `/admin/order-items/{orderItemId}/license-letters` | itemId/includeVoided → LicenseLetterList |
| `admin.licenseLetter.correct` | POST `/admin/license-letters/{licenseLetterId}/correct` | LicenseLetterCorrectBody → AdminLicenseLetterView |
| `admin.licenseLetter.void` | POST `/admin/license-letters/{licenseLetterId}/void` | LicenseLetterVoidBody → LicenseLetterVoidResult |
| `admin.licenseLetterRevision.rerender` | POST `/admin/license-letter-revisions/{licenseLetterRevisionId}/rerender` | revisionId/严格空对象 → LicenseLetterRevisionView |

| 唯一 x01 | 责任 |
| --- | --- |
| `docs.onRevisionQueued` | 原事件触发实际版次任务，不再实现一份授权收敛 |
| `docs` 队列 | 并发2；认领/渲染/上传/条件提交，保留租约、重试与取消 |

- 只扩已有 `docs.sweep`：queued 超时重投、rendering 租约回收、满次失败；不注册第二个同名周期任务。
- 更正调用 W5-06 同一收敛/快照出口；内容未变返回 LICENSE_LETTER_UNCHANGED，不修改上游名称事实。
- 作废后依当前账号集合决定重建，保存旧信；rerender 只接 failed，queued 缺签名能力不能伪装失败重试。
- worker 认领后在事务外渲染/签名/存储，提交核认领序号；迟到结果不得覆盖新认领或更新后的法律事实。
- 实装docs消费者及关闭排空；自有M1 scope的排空须覆盖实际queued/rendering任务、ready条件提交和issued后续。outbox为空、订阅投递done或队列waiting为0均不能单独证明渲染完成；后台observer只读，不代consumer写终态。
- 下载缺省取当前ready版，显式revNo可取本信件历史ready版；新版生成中如实呈现上一版与生成状态，不签不存在的PDF。
- 对象键带最终文件哈希，落库文件/哈希一致；内容指纹印页脚，不能把文件自身哈希印进文件冒充相等。
- 沿ADR-042静态TTF、并段换行、控制字符规范化、页脚及字体读回。业主2026-10-30已定：缺字即暂停该版出件，提示具体缺字，修正资料或字体后重试；不得换成“〓”继续出件或前移ready。字体修正后按原重试规则重渲同一不可变版次；资料修正走更正重出生成新版，不回写旧snapshot。
- 授权书含主体敏感信息：老板范围、后台真实权限、5分钟私签、no-store、每次访问审计与二次可见性校验。
- 签名适配复用现 `EsignProvider.seal`，如实区分 certificate/stamp/unconfigured；生产不静默降级为图片章。
- 必须交经核准CA协议的真实certificate适配/配置与错误边界；依赖未准入先独立前置，不能默认放弃真实driver或用stamp假完成。
- 唯一回补 `docs/plan/stubs/m5-order-aftersales-licenses.md`：取消读 W5-02 公口，授权读本域公口，order 不反查私有 docs 表。

当前八条为meta-only，本包按上述主API结构补strict schema及真实挂载，不能冒称现已有完整typed实现。
本包0新页；合同页/订单详情由页面包消费；验真/portal不暗增API或新页，保留后继公开形态移交。

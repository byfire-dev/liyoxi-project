## 1. 目标

交“我的短剧”1新页，补已有确认订购、样片与订单详情；0新增API/x01。
只消费实际后端报价、广告、取消与授权事实，不在页面计算积分去向或重建授权。

| 页面key / route | 本包边界 |
| --- | --- |
| `sub/order/my-dramas/index` | 唯一新页，按订单项列剧目、账号、使用期、上线状态与服务端页签计数 |
| `sub/order/checkout/index` | 已有页选可用广告，带真实adIds重取报价，确认当前版本与实际应冻结积分 |
| `sub/order/sample/index` | 已有页提合成修改意见、截图、查看证据与新版本失效；广告内容跳实际广告 |
| `sub/order/order-detail/index` | 已有订单售后/取消进度及授权事实展示，不新增详情路由 |

| 消费operationId（不重复拥有接口） | 使用事实 |
| --- | --- |
| `m.orderItem.list`、`m.orderItem.summary`、`m.orderItem.get` | 订单项游标、页签与真实使用期；不得将订单行冒充剧目行 |
| `m.order.list`、`m.order.get` | 当前门店订单与逐项售后、授权投影，取消中/执行后状态准确 |
| `m.order.quote`、`m.order.create` | 广告选择变更后真实报价、同意、冻结积分及原幂等意图 |
| `m.ad.list`、`m.ad.get` | 当前门店可选已确认版本及详情跳转；其他门店/在途取消不可选 |
| `m.orderItem.sample.get`、`m.sample.downloadUrls`、`m.sample.confirm` | 原样片GET、现签水印版与真实viewedVia/业务版本 |
| `m.sample.requestChange` | 仅实际typed正文的compose、note和imageFileIds；GET核change_requested |
| `m.licenseLetter.list`、`m.licenseLetter.get` | 订单授权引用/查看；完整合同列表与PDF操作交W5-12 |

请求/响应从`@liyoxi/contract/types/merchant`的operations推导，query/body对照上游实际schema，不复制DTO。
A31优先于旧样片桩误述：不造默认播放器、进度条时间点或feedback_time_ms字段。
样片修改不拼lockVersion/versionNo等未声明字段；样片ID锁定实际版本，迟到响应不能覆盖新版本。
确认继续用服务端confirmableVia与已有访问证据；不将点击“查看”当保存/预览成功。
广告内容修改导向本门店实际adId，不能把广告扣次混入免费合成问题修改。
换门店、换主体、退出、卸载与新版本到达均废弃旧草稿/确认；失败重试复用同意图key。
订单售后/授权reader由W5-07单写并凭真实后端投影独立闭桩；本包仅按实际页面行为回补自己的两个UI桩。

## 1. 目标

交广告只读预览与无需会话的授权书验真两页，保持Q9一期样片仅小程序查看。
拥有接口：无；0新增x01。新页2、旧页0；登记名仍含样片不构成恢复样片电脑预览。

| 页面key / route | 唯一边界 |
| --- | --- |
| portal.preview / /preview/$kind/$id | 广告元数据/播放；kind=sample按Q9受控说明/拒绝，无查看确认入口 |
| portal.verify / /v | 公开验真；code与rev映射实际API，状态/版本/签名说明脱敏 |

| 消费operationId（不重复拥有API） | 实际用途 |
| --- | --- |
| portal.ad.get/playbackUrls | 广告详情/版本及实际播放签发/访问留痕；ad.list与/items广告分区唯一归W6-11 |
| portal.licenseVerification.get | 公开查询code/revNo，当前状态与扫码版本区别 |
| portal.clientError.create | 全portal安全错误上报接线，复用W6-10客户端边界 |
| portal.orderItem.sample.get；portal.sample.playbackUrls | 按Q9一期不实现；06先正式冻结治理，本页不生成样片地址、不以拒绝handler计落地 |

广告仅预览，不提供确认、修改意见或计费动作；这些动作返回小程序的既有入口。
广告元数据GET零写，播放签发POST留痕；旧版本、吊销会话和跨店访问按服务端拒绝。
样片路由不回退至相册/企业微信/电脑播放；历史sample.view能力和字段保留不等于当前开放。
验真页不要求portal会话，不展示老板联系方式、门店敏感信息、私有签名URL或PDF下载入口。
前端rev原样传revNo；无效/缺省版次、作废、过期、重签与当前有效版本按实际投影呈现。
验真查询无业务写入，no-store及限流由后端保证；不以本地解析PDF代替官方状态。
错误上报只含允许的安全字段；清理code/pollSecret/Cookie/签名URL/业务原文，不把telemetry当业务成功。
W6-10共享壳只由本包最终接入错误writer；接口未合时不造成功或另建匿名上报通道。
本包唯一接收sample-computer历史桩，待06正式治理actual后按Q9说明与负例收口；不恢复电脑样片或称其功能已实现。
E8/E11按各自原最晚点；签后阅读器V12最晚M8进入前有结论，测试证书验真页面不能关闭该项。

## 5. 不做什么

- 不做样片电脑播放、查看确认或修改，不以关闭内播为恢复其它渠道的理由。
- 不从公共验真接口下载私有PDF、披露机构密钥或扩大匿名可见字段。
- 不改授权收敛、签章、作废或广告生命周期；只消费actual投影。
- 不新增V1.1电脑上传、购买/价格/支付入口或真实外部发送。

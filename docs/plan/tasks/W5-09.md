## 1. 目标

后台能在真实权限和数据范围内处理广告，指派、版本推送与查看证据都落在实际当前单据上。
员工在办与移交须包含真实广告，不再因未登记广告来源而漏计或漏移交。

拥有接口（10条；原实际contract的权限、再验证、幂等、路径与M5归属不变）：

| operationId | 方法与实际路径 | 请求 → 响应结构 |
| --- | --- | --- |
| `admin.ad.list` | GET `/admin/ads` | 页签/范围/排序/分页查询 → AdminPage&lt;AdTaskCard&gt; |
| `admin.ad.get` | GET `/admin/ads/{adId}` | 范围内adId → AdTaskDetail |
| `admin.ad.summary` | GET `/admin/ads/summary` | 同列表去页签/排序/分页 → AdSummary |
| `admin.ad.assign` | POST `/admin/ads/{adId}/assign` | AdAssignBody → AdTaskDetail |
| `admin.ad.return` | POST `/admin/ads/{adId}/return` | AdReturnBody → AdTaskDetail |
| `admin.ad.requestChange` | POST `/admin/ads/{adId}/request-change` | AdminAdRequestChangeBody → AdTaskDetail |
| `admin.ad.remind` | POST `/admin/ads/{adId}/remind` | adId/严格空对象 → AdminRemindResult |
| `admin.ad.adVersion.create` | POST `/admin/ads/{adId}/ad-versions` | AdVersionCreateBody → AdTaskDetail |
| `admin.adVersion.push` | POST `/admin/ad-versions/{adVersionId}/push` | AdVersionPushBody → AdTaskDetail |
| `admin.adVersion.markSent` | POST `/admin/ad-versions/{adVersionId}/mark-sent` | adVersionId/严格空对象 → AdminAdVersionView |

| 唯一 x01 | 责任 |
| --- | --- |
| `sla.breach`（主体ad） | 首版/修改版分别核当前purpose、轮次和deadline，发ad.sla_breached |

- list/summary/get按同一数据范围/筛选口径；游标与稳定排序沿typed契约，不以前端过滤凑正确计数。
- 指派只接受启用剪辑师与实际员工集合；资质未通过、在途取消拒绝，锁内重核并经08公口capture一次。
- 首次指派无旧负责人，不造 assignment_history；后续离职/调岗通过原员工移交体系，不新增广告改派HTTP。
- 版本登记只消费当前员工上传、实际stored与体检ready的广告文件/制作事实，保留AI留痕与分段合法性。
- 上传版本与推送版本分离；未推送商家不可见，推送快照preview_channels，满足本轮SLA后只关闭对应timer。
- markSent只记录真实线下发送/查看方式及操作者证据，不把上传成功、播放GET或员工单方面声明当商家确认。
- 代商家提修改只限免费次数内，超次拒绝、不能代勾付费；沿08同一轮次公口，保原代理权限与来源。
- 手工催办通过原通知框架与节流，未配置/失败如实返回；不宣称消息必到达，不新增未发事件名。
- 退回补充只取消当前首版timer并沿08登记待补充到期；恢复后的旧timer不得污染新resubmit_count。
- SLA用原快照/工作日历；资质在审待指派只提醒不写违约，首版/修改版分别核已满足事实再记时限结果。
- 注册真实typed staff来源：广告当前负责人/当前在办集合、count/list及owner reassign均由ad私有实现。
- 员工禁用/转移先锁员工与业务行，再由ad owner重核归属和目标角色，原assignment/history/SLA事务内一致。
- staff低层仅消费既有typed source，不查询ad表；08不反向依赖本包，不能将staff缺登记冒充零在办。
- 广告读/写经08已合窄公口；广告取消HTTP入口归08、申请/审批公口归02、唯一执行归01，本包不另建审批或退积分机制。

本包0新页、0桩关闭；后台 `delivery.ad_tasks` 页面由专属页面包消费这些真实DTO。
当前十条为meta-only；PR2按主API补strict schema/实际挂载，四种证据为weapp/album/portal/wecom，不能伪造M6 portal完成。

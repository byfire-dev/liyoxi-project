| 项 | 内容 |
| --- | --- |
| 组 / 里程碑 | G2-B / M2 |
| 规模 / 级别 | L / 丙 |
| 交付边界 | 0 新接口；6 新登记页；0 x01/桩归属 |
| 分支建议 | `feat/W2-14-store-members`，从实际 main 开工 |

## 1. 目标

交门店管理、新增门店、店员档案、成员、邀请和加入六页；原档案页补资质多轮入口，后台与素材不在本包。
所有可写按钮按 actual DTO actions/能力点与当前身份显示；额度、资格、成员范围由服务器判定。

| 页面 key / 地址 | 可见与核心链路 |
| --- | --- |
| `sub/profile/stores/index` | owner 门店管理、选店、归档/恢复/草稿删除；clerk 仅服务器许可门店 |
| `sub/profile/store-add/index` | owner 新建门店；额度卡、资料输入与返回实际 storeId |
| `sub/profile/staff-profile/index` | 仅店员本人档案；不呈现 owner 的资质/财务写动作 |
| `sub/member/members/index` | 成员/邀请摘要与 SeatInfo；owner 管理、clerk 按裁剪查看 |
| `sub/member/invite/index` | owner 邀请、手机号限制、分享与撤回 |
| `sub/member/join/index` | public 预览；登录/同意后接受，四种异常分支 |

消费 W2-10：`m.store.create/archive/delete/restore`、`m.member.list/update/remove`、`m.me.membership.leave`、五 invitation 接口。
消费既有 `m.me.get`、门店列表/当前选择 API 和 W2-11 的 qualification 轮次/文档/联系人操作；不新建后台 Route。
直接使用 `StoreCard/EntityQuotaCard/MemberItem/SeatInfo/InvitationCard/InvitationPreview/MembershipResult/StoreBlocker` 与实际 profile DTO。
join 状态至少 pending、accepted、revoked、expired；坏 token/不存在单独正常空态，不向未登录用户泄露手机号或完整主体信息。
分享后的 `markShared` 只记分享事实；没有分享成功回调时不自动把邀请当作已经接受。
新增店提交成功用返回 ID 后读；不能拿列表第一项或旧 X-Store-Id 作为新门店。
chooseLocation 仅业主申请通过且隐私配置就绪时开放；默认沿 M1 省市区＋手填地址，不传虚构坐标。
既有档案 `sub/profile/store/` 中 initial/change/new_store 的多轮入口是增量，不计第七页，不改 M1 文件上传组件。
表/状态机/事件/定时器：本包全部 0；租户 expiry、状态迁移与通知由 W2-10/11/17 持有。

## 5. 不做什么

不把 clerk 提升为 owner、不新增后台成员新增 API、不做账号注销/老板更换 UI。
不实现素材上传中心、portal 授权、模板消息中心或自己安排 invitation.expire。
不自算 seats/quota/能否归档；业务 blocker 使用服务器 details，不过滤有真实业务的门店。
不把 public join 的预览当鉴权成功，不在 URL/日志保存手机号、邀请码明文或临时微信 code。
不改通用构件、platform/request/context 框架或上传协议；平台扩展必要时独立构件 PR。
不改服务器状态、权限或门店范围，不删除旧页面/H5/黄金场景、调高预算/门禁。

## 8. 需要业主做的事

开工、合并前无。地图入口需要业主已办 chooseLocation/隐私用途申请结果，未过则原地址路径仍可交付。

短信/模板配置由 G2-D 接，不在页面包发真实短信、收集真实成员信息或操作服务器。

## 9. 交付与默认

六页一条丙类 PR；三个 profile 与三个 member 子域私有分工，不额外登记弹层为新独立页。
status 回写真实六页、既有档案增量和地图外部未验；任务整体完成不包含后续后台/素材/portal。
接受邀请前用当前协议版本/登录态提交；STALE 后重取版本，不能缓存一次同意永远放行。
页内写后刷新与列表分页绑定读代次，操作所有权和忙态收尾独立，旧 finally 不清新锁。
默认 pending 且 expiresAt<=serverNow 在 lookup 被展示 expired，页面不发隐式写请求来补过期。
owner 可读 by_owner 归档、clerk 不可；恢复和新建的继续动作取实际返回上下文，不硬拼第一个门店。
作者本地普通提交和五节正文、绝对截图交调度；一轮独立复审后 CI/定点闭环。

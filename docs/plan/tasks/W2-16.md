## 1. 目标

交后台协议管理主从页：六份协议清单、版本详情、草稿编辑、安排/撤回与同意记录查询。
页面只消费 W2-12 实际接口，不代替 docs 解析生效版本、计算公告资格或保存签名 URL。

| page key | 地址 / 范围 |
| --- | --- |
| `ops.agreements` | `/ops/agreements`；协议卡、版本主从、同意记录、草稿/安排/撤回弹层 |

本包一页；编辑器与同意记录为本页私有面板，不额外创建未登记页或复用后台商家详情路由。

| 消费 operationId | typed 结构与交互 |
| --- | --- |
| `admin.agreement.list` | `AdminAgreementListQuery`、`AgreementListItem`，六协议卡 |
| `admin.agreement.get` | `AgreementDetail`，当前/pending/draft phase 与 actions |
| `admin.agreement.agreementVersion.create` | 新草稿返回值；真实 id 后继续编辑 |
| `admin.agreementVersion.update` | source/pdf、摘要、生效时间、reconsent、法务字段与 lockVersion |
| `admin.agreementVersion.schedule` | 服务端最早时间/公告不足/stepup/文件守卫，重取详情 |
| `admin.agreementVersion.withdraw` | withdrawn、newDraft|null、siteNotice|null，原版不当 draft 继续写 |
| `admin.agreementConsent.list` | `AgreementConsentItem` 筛选/分页，实际签署与脱敏 |
| `admin.agreementConsent.get` | `AgreementConsentDetail`、证据/快照与文件现签 |

Word/PDF 上传走现有 uploader 的 legal_doc 分类与真实上下文；文件入库后再提交版本引用，不只拿预上传 ID。
法务 checkbox 记录经授权用户真实操作，默认不勾；E8 未提供正文明确占位，不暗示可以发布生产。
版本 phase/actions 为服务端事实；生效恰逢 sweep 未翻状态也按服务器返回展示，不本地挑 active。
只呈现 actual 六协议，partner V1.1 不增加；签名 PDF 每次取当前 URL、客户端不长期缓存。
表/状态机/事件/定时器：本包全为 0；docs.sweep/consent_digest、公告与版本迁移在服务端。

## 5. 不做什么

不写 backend/docs/config/notices 算法、契约 metadata、系统 cron 或协议内容渲染 Provider。
不在浏览器算最低公告期/是否可撤回/用户重同意进度，不将客户端时间当服务端 now。
不把安排/撤回失败默认为成功，不把已撤回原版本编辑成同 id 的草稿，不覆盖已有草稿 null 语义。
不预勾法务、不加载真实合同/手机号、不自行放宽源文件/PDF 默认或 legal_doc 分类授权。
不改已冻结主从表格、UploadField、date-range、PII/mask 与主题；必要通用修复走独立构件 PR。
不手改生成物/黄金/门禁、不提高预算，不把 H5/替身签名当真实对象存储验证。

## 9. 交付与默认

丙类一页、一 PR，版本 editor/同意详情是本页面板；未来 ops 公告/通知页不算本包完成。
协议当前版本、是否重同意、公告与可操作动作取服务端；页面只收输入、显示结果、重新读取。
step-up 后同一请求意图复用 key；用户真正改字段后另 key，不能无限重试 stale lockVersion。
所有含签名 DTO 不缓存于 query 之外的持久化；每次下载重新发 GET，C18/C50 语义来自 W2-12。
状态记录 1 page/0 新 API、真实 live 与外部未验；E8 placeholder 没回填不称协议法律已交付。
交绝对截图路径、样例和 live 命令/结果、键盘事实、准确体量与默认项，原场景保持完整。
作者正常本地中文提交交调度；sole 独立复审后 CI/定点闭环，不补第二正式审查。

## 1. 目标

落地数据字典、参数配置、开关管理和清单模板四页；配置管理员可通过真实 API 编辑，普通查看者只能读取允许内容。
参数页内提供年度日历读取/内置安排导入，预约参数生效/撤销与冲突提示；不再加一个日历页。
所有配置先读服务端元数据和 actions，写后刷新真实版本，不在前端复制参数定义、轮询算法或配置写侧。

页面逐项范围（4 项，原登记路径/里程碑保留）：

| pageKey / URL | 骨架与闭环 |
| --- | --- |
| `system.dict` / `/sys/dict` | SysDict master-detail；类型/层级列表、详情、合法新增/改名/启停与引用阻断 |
| `system.params` / `/sys/params` | SysParams config；分组、类型输入、当前/预约值、整批保存/预约撤销、工作时段/年度日历 |
| `system.flags` / `/sys/flags` | 无画板 query-table；完整规则/缺省值/版本，超级管理员编辑与确认 |
| `system.checklists` / `/sys/checklists` | 无画板 query-table；编码/版本状态、草稿条目、新建/启用/放弃和只读历史 |

默认：flags/checklists 保留 inMenu=false、parent=system.params；参数页放可访问子页链接，权限不足不显示。它们仍是两个独立登记页，不隐藏实现事实。
接口仅消费 W2-05 的 13 条与既有 dictItem.list/checklistTemplate.list；不新增操作接口、表、状态机、事件、定时器或页面弹层登记。
字典页取类型 canCreate/maxDepth/停用规则等真实信息；code、type、parent 不可编辑。服务器生成编码；in-use 409 显示真实 refCount，历史被停用项仍显示名称。
schema 的 fieldErrors.path 映射到具体 ext/条目，不在 UI 放开 backend 禁止的行业/open、系统枚举或行政区划编辑。
参数控件由返回类型/单位/范围构造，值不转成无类型字符串；保存时提交每键 expectedRev。先显示 current/pending/source，预约须显式 effectiveAt，不能把立即保存误写成撤销预约。
多个键一批一个幂等键；任一 409 刷新冲突键并保留用户可识别的草稿，重新确认后再提交，不悄然覆盖。
日历默认业务北京时间年份，year 用正式 2024–2100 边界；页面只调用不带 days 的内置导入，成功展示 changedDays/批次，未导入状态明确显示。
工作时间开始小于结束、数值范围等前端可预校验，服务器仍为最终依据；日期/时间不依浏览器本地时区偷换。
开关只超级管理员可读写；显示已有规则顺序/维度/缺省分支，不引入“审核态”规则或绕安全开关。生效与告警事实以响应/重读为准，不伪造 evaluator 预览结果。
清单固定 9 个已登记 code，条目 key 唯一，required/allowNa/merchantVisible/hint 按契约。草稿无修改接口：更改通过放弃旧草稿再创建新版本。
启用旧 active 自动 retired，前端刷新新版本；草稿放弃为 retired，不叫 deleted。旧业务清单快照保持只读，页面不能改历史结论或声称既有提交自动升级。
required 操作沿既有提交/确认/再验证；重试保留键，实质 body 改动换键。按服务端 actions/权限渲染，不能只隐藏按钮却开放路由。
筛选/主从选择按 validateSearch 校验并写 URL；未保存更改离开前用已有保护，恢复/错误/空态不丢选中对象，键盘焦点能回到触发元素。

## 5. 不做什么

- 不增日历第五页、参数历史独立页或额外配置类型；不移动既有页面/接口里程碑。
- 不改生产 services/API/contract/schema、参数默认值、开关默认或字典生成规则，不在前端查 DB。
- 不改共享组件、主题/tokens、骨架、mask/validateSearch机制；需要增强交 W2-02 后续独立构件 PR。
- 不改 live 起栈/Playwright 配置，不在浏览器拦截真实 API 伪造成功，不持久化操作明文或凭据。
- 不做在线抓取/自定义 days 导入表单、审计导出或计费参数页；计费参数由 W4-07/W4-17 接。

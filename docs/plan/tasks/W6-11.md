## 1. 目标

交电脑可下载清单、成片下载两页及既有小程序逐集保存队列完整版；/items将订购项与待确认广告分区展示。
拥有接口：无；0新增x01。新页2、旧页1，评审页面总数3；并发与恢复使规模按L评审。

| 页面key / route | 唯一边界 |
| --- | --- |
| portal.items / /items | 订购项与待确认广告独立分区/游标/空态，当前门店范围、下载阻断事实与广告预览入口 |
| portal.item / /items/$id | 逐集、ZIP、发布清单文本/文件与真实下载状态 |
| sub/publish/downloads/index | 旧页；原逐集保存扩为有界队列、恢复、回报、重授权及电脑扫码入口 |

| 消费operationId（不重复拥有API） | 实际用途 |
| --- | --- |
| portal.orderItem.list/release.get | actual订购列表/包manifest、下载资格与阻断原因 |
| portal.ad.list | 同门店待确认广告独立分区、游标/空态及跳转W6-12预览；不把广告伪造为orderItem |
| portal.orderItem.downloadUrls | episode/zip/publish_list签发，none幂等、每次实际留痕 |
| portal.orderItem.publishList.get；m.orderItem.publishList.get | 文本复制与无ZIP时本地文本文件退路 |
| m.orderItem.downloadGrant.create；m.download.report | 显式重授权、真实下载/保存结果回报 |
| m.orderItem.release.get / 既有逐集签发入口 | 复用actual契约及W1-20已合实现，不沿D7旧伪代码造/m/downloads/ack |

每次下载现签，地址不写本地进度/日志；GET仅展示事实，点击或轮询签发POST的访问记录不能省。
ZIP building按pollAfterSec=5轮询且retry=false；10分钟未就绪停止并提示逐集下载。
failed必须用户显式重试才retry=true；发布清单文件非ready时取真实文本生成文本文件，不为文本偷偷打包。
小程序没有ZIP存相册；并发2与自动重试3次沿原规范，每次重试取新地址，不扩大网络并发预算。
下载使用tempFilePath，保存后立刻清理；失败/取消清残留，不写USER_DATA_PATH塞满用户目录。
进度按门店和releaseId隔离；补发包只默认勾选变更集，旧包状态不覆盖新包。
蜂窝下载前确认；后台中断回queued，前台恢复；取消后不继续签发，换店迟到结果废弃。
saved只在真实save成功后回报；客户端确认不冒充平台已发布或后台核验通过。
本包独占episode-save桩；saved-progress/ZIP/发布清单后端桩各归W6-06/07/02。
tasks页清单复制与下架归W6-09，本包不并改该页；从既有下载入口自然进入本页。

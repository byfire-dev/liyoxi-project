## 1. 目标

建立唯一的使用期顺延、到期重算和事务内收尾机制；订单、交付、发布与下载共同消费同一事实。该甲包只交使用期一致性机制，不扩为发布 CRUD 集合。

拥有接口：无；只交本包单一机制及以下已登记异步项。

机制与移交：

- 版权顺延订阅只为实际受影响订单项登记 usage.resync；复用已合 order 对账补偿，不另建第二套扫描。
- usage.resync 锁后核 usage_end_source=license、工单阶段与当前版权版次；只顺延，不缩短，不复活已归档或终止业务。
- 顺延按原守卫重开最后一个因到期关闭的成片包；不复活取消/终止版本，也不覆盖历史下载证据。
- usage.end 按 Asia/Shanghai 止日次日零点执行；所有日期守卫读锁后事实，旧代定时器只能 skipped。
- 在唯一事务中进入到期下架、关闭或结清上线任务、作废巡检、撤销下载授权、关闭补发跟进；保留原历史与审计。
- 本包先交 publish.ensureTakedownTasks 等最小公开到期原语，负责唯一任务生成与顺延作废 writer；W6-04 仅消费，不反向依赖04的API/处理器。
- 推包与顺延按前缀取消旧 usage.end、takedown.create 后登记新目标；本包拥有使用期重排，04拥有下架定时器处理器。
- 消费已合 closeExpiredDeliveryPublish、resyncDeliveryPublishExpiry 与 delivery reevaluate，保持审批锁先于领域锁及完整预锁图。
- 时间推进后仅在原文允许的终态收尾；到期下架后全部商家确认的归档触发由04补齐，本包提供可复用事实。

唯一拥有x01：`usage.end`、`usage.resync`、`publish.onLicenseExtended`。
唯一回补桩：无；只给对应owner提供本包证据，不回写他人桩状态。

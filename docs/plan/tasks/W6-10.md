## 1. 目标

交电脑扫码、会话失效、扫一扫落地三页及小程序扫码确认页，接设置页已授权电脑管理。
拥有接口：无；0新增x01/留桩。新页4、旧页1，评审页面总数5；失效说明不另造URL。

| 页面key / route | 唯一边界 |
| --- | --- |
| portal.login / / | 二维码、两位配对数字、倒计时与手输代码入口 |
| portal.expired / 无独立地址 | 当前会话401后按服务端reason解释，再回扫码 |
| portal.landing / /a | 微信扫一扫打开时的真实操作提示；不在H5擅自批准 |
| sub/publish/portal-approve/index | 老板在当前门店核对浏览器/地区/时间/配对数字并批准或拒绝 |
| sub/service/settings/index | 旧页；已授权电脑列表、当前状态与显式吊销 |

| 消费operationId（不重复拥有API） | 实际用途 |
| --- | --- |
| portal.portalTicket.create/get/exchange | 建票据、轮询与一次性换会话；pollSecret只在内存 |
| portal.session.current.get/delete | 只读会话、退出、吊销/过期/资格变化的统一失效处理 |
| m.portalTicket.lookup/approve/reject | 按当前门店/老板权限和配对数字授权，重放/并发结果由后端裁决 |
| m.portalSession.list/revoke | 设置页列表与吊销，实际状态刷新 |
| portal.clientError.create（W6-06后续提供） | 本包仅定义typed接线槽；W6-12实际接入，未合前不得发送或造成功 |

票据状态pending/approved/rejected/expired/consumed分开；按原2秒节律轮询，终态/离页即停止。
pollSecret不进入URL、localStorage、日志、错误附件或截图；旧轮票据响应不覆盖新二维码。
会话Cookie由后端HttpOnly/Secure/SameSite=Strict下发；前端不读/保存原token，不自制Bearer旁路。
非GET带X-LYX-Portal与同源Origin；none路由不套后台Idempotency-Key。
授权门店固定；换店、取消或失去老板资格时清旧确认，已停用店按实际后台规则展示。
只读壳不出现价格、积分、套餐、购买/付款引导；统一401、429和维护态供W6-11/12复用。
共享App/typed客户端/路由壳由本包PR1先交；W6-11/12只加自己叶页，不复制会话状态机。
PR1只做固定当前同源API基址的typed transport（不从URL/query接受origin）、真实会话读取/退出/失效、401/429/维护态和secret内存边界；路由扩展保留各叶owner与公开/会话访问区分，不预建业务页或伪造登录成功。若含UI，仅呈现真实会话边界，不提前计本包4新页完成。
二维码、登录完整交互、/a落地页与小程序审批/设置完整版归PR2；PR1不选择扫码形态、不消费X-01未合探针，也不新增绕过授权的生产测试入口。
设置页吊销后再次请求必须失效；页面消失不等于后端已注销，不乐观伪造结果。
无合法扫码结论不得开启真实形态；V8失败按正式结论切普通二维码加手输代码。

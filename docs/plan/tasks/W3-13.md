## 1. 目标

落地sub/catalog/search/index并接既有首页/商城搜索入口，实时调用W3-11真实搜索；回补m3-weapp-mall-search。
热词来自已发布mall配置，历史只存本地最多十条；匹配与兜底模式/价格/权限由服务器给出。
actual mall已真实列表/筛选/分页与contextRev切换保护，仅追加入口/搜索页，不重写商城资源或全局状态机制。

要落地的页面（1条）：

| page key | path / 可执行行为 |
| --- | --- |
| `sub/catalog/search/index` | `sub/catalog/search/index`；输入/热词/历史→真实search，结果进详情、返回保留商城上下文 |

HTTP/x01/timer：无新增；调用m.drama.search、m.mallConfig.get，详情走已有DeepLink/page；无新留桩。
输入最多20字、去空格/“·”按契约归一，空输入显示热词/历史、不发送非法q；确认/点热词/历史立即搜，输入防抖默认300ms可局部常量修改。
防抖/请求序号/当前query/contextRev/token共同校验，旧关键词/旧门店/旧身份响应不得覆盖当前结果/错误/分页状态。
history本地去重/新词置顶/最多10条、清空真实storage；只在实际搜索提交后记录，不每键存、不写数据库/埋点/日志。
热词来自mall.hotWords最多8项/按顺序，不显示V1.1热/新标签，不硬编码示例“家庭喜剧”或虚假推荐结果。
match模式按matchedFields局部安全切分高亮，文本作为React/Taro文本渲染；不注入HTML，不前端改变title/genre/cast匹配排序。
industry_fallback显示服务端fallbackIndustry提示与真实卡片；关闭兜底/空结果显示空态，不使用热词卡片假冒查询结果。
totalApprox按服务器值显示“找到N部”与999封顶语义，hasMore/nextCursor驱动加载；首屏/更多独立loading/error/retry，不丢已加载项。
新的关键词/身份/门店切换清游标/续页，单轮more去重；旧请求finally不得清新轮loading，页返回资源依据现有contextRev模式。
owner/clerk/guest按viewerRole/viewerPlan与真实字段裁剪，店员不能计算出隐藏积分价/购买入口，服务器权限不足显示真实提示。
商城既有筛选/排序/分类返回保持，搜索页进入/结果卡片到详情仅传合法dramaId/来源page，不把关键词当鉴权参数。
已有track白名单只按实际详情/分享等点位调用；不发未登记drama_search、不把q/history放任何AnalyticsCode/自由文本props。
键盘确认/取消/清空/返回、安全区/长题名/高亮换行/网断重试覆盖；预告片feed默认关闭，不借搜索打开播放/支付。

## 5. 不做什么

- 不改backend/HTTP/metadata/全局状态或contextRev机制，不重算可见/价格/搜索/行业推荐。
- 不建搜索历史表/云同步/自由文本埋点、不记录手机号/令牌/用户输入到日志，不新增事件点位。
- 不重写商城/详情/预告片，不新增颜色主题/硬编码hex/第二区域搜索页，不开发V1.1热词标签。
- 不运行真实微信/发布/短信/云配置操作；开发者工具通过不标真机/生产联调已验。

## 6. 允许新增的依赖

无。复用现有Taro/组件/契约客户端/storage/资源模式，局部可拨时钟单位测试，不装搜索/状态库。

## 1. 目标

交付 media 域的素材、需求、复核及理解管线；20 API、0新页、2 x01，回补3项桩。
当前素材路由只有 meta；服务、请求/响应 schema、真实 handler 与测试均须新增，不能宣称已有可调用实现。
要落地的接口逐项如下；结构依 m03§2.7/a03 素材节新增本域 schemas，实际字段逐条对账。
新增 `StoreAssetCardSchema`、`StoreAssetDetailSchema`、`StoreAssetSummarySchema`、`AssetDemandItemSchema`；请求按各接口正文命名，公共结构只一处定义。

| 技术维度/操作 | 原值→新值与守卫 |
| --- | --- |
| processing_state 创建/首任务 | —→pending→processing；父素材锁下建任务 |

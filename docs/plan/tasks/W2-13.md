| 项 | 内容 |
| --- | --- |
| 组 / 里程碑 | G2-B / M2 |

| 分支建议 | `feat/W2-13-account-settings`，从实际 main 开工 |

## 1. 目标

增加设置页，把“退出登录”从我的页移入；完成本人称呼、换绑、已登录微信与注销的真实操作。
将已合登录 PhoneForm 的替身按钮替换为真实手机号验证组件；沿 V19 默认，未通过时按实际配置受控降级。

| 页面 key / 地址 | 范围与数据 |
| --- | --- |
| `sub/service/settings/index` | 新增设置页：账号与安全、退出/注销、隐私协议、通知设置、已授权电脑入口 |
| `pages/login/index`（既有增量） | 微信手机号组件、隐私授权、同意版本与原 returnUrl/query |
| `pages/mine/index`（既有增量） | 仅设置入口与退出位置移动；保留八态及既有角色裁剪 |

本包只有 1 项新页；账号编辑/换绑/解绑/注销在设置页私有弹层，不暗增未登记路由。
只消费 W2-09 的个人接口：`m.me.update/changePhone/deletion.create/userNotice.acknowledge/wechatIdentity.list/wechatIdentity.delete`、`m.smsCode.create`。
已有接口：`m.me.get`、`m.session.phoneLogin`、`m.session.current.delete`、协议 list/version 与既有同意提交流程。
结构直接取 `MeView/MeUser`、`WechatIdentityItem/WechatIdentityRemoveResult`、`SmsCodeResult/UserNoticeAckResult/DeletionResult`、`AgreementCurrent`。
换绑提交 `oldSmsCode` 与真实组件 `newPhoneCode`，当前令牌保留；删当前微信或注销成功须清本地登录态。
一次性提示按服务器 `userNoticeId` 关闭；失败保持可重试，不自行当作已读。
通知设置只接已实现平台/引导入口；消息业务列表属 W2-19，不在本包复制。
已授权电脑的 list/revoke 属后续 portal 包：在接口 actual 前显示明确未开放状态，不调用 Meta-only 路由或假造会话。
表/状态机/事件/定时器：本包全部 0；页面不得写库、发出站事件或代替服务端完成绑定/注销。

## 5. 不做什么

不落地 portalSession API、下载扫码、HLS、后台账号变更与角色维护，不把后续电脑入口做成虚假成功按钮。
不在 H5 模拟真实 getPhoneNumber 成功作为外部验收，不硬编码 AppID、短信模板或备用手机号。
不修改 `lib/request`、公共 platform wrappers、bootstrap 结构、同意拦截框架与通用陈列构件。
不把手机号明文、openid、验证码、临时 code 放日志/埋点/本地持久化；不把被解绑身份的旧令牌继续使用。
不自算服务端注销 blocker/count/actions，不因新隐私未同意隐藏允许注销的入口。
不修改 backend/contract Route、权限、DDL、layers 或其他页的实现标记；不放松旧八态与 clerk 黄金。

## 9. 交付与默认

丙类 1 新页单 PR；登录/我的页增量单列统计与截图，保留未来页面登记，不扩成为账号中心新包。
未登录可看隐私/协议与设置说明，受保护动作引导登录，返回路径的 query 原样保留。
账号修改与写后刷新绑定读代次；同步忙态/所有权独立，刷新失效后仍能收尾并开始下一操作。
默认执行当前 V19，不能把“免费/收费”猜测写成生产配置；平台事实取实际引导与服务端错误。
当前换绑不吊销电脑会话；禁用/注销/老板更换按服务端动作处理，不在端上模拟连带效果。
通知与电脑能力只展示 actual 可用项，尚未实装明确移交 W2-19 和后续 G6，不虚报整套设置已开放。
作者本地中文提交、五节正文与截图交调度，一轮独立审查；仅真实平台/外部事项保留未验证。

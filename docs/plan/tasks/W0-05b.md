## 10. 实现要点与顺序

1. 库名守卫：一个函数，建库、删库、重置、连接四个入口都先过它，不符即抛错，一句 SQL 都不发。先写它的失败用例。
2. 模板库：`globalSetup` 里建模板库并 `migrate deploy`。`CREATE DATABASE … TEMPLATE` 要求模板库上没有别的连接，建完即断开。
3. 按 worker 建库：worker 编号取 Vitest 提供的环境变量；首次取连接时建库。测试成功即删库；失败保留并打印库名。
4. Redis：按键前缀隔离；“清空”用 `SCAN` 加 `UNLINK`，不用 `FLUSHDB`、`FLUSHALL`。
5. 可拨时钟与四种故障注入工具，各带自测。
6. `test:isolation`、`test:db:prune`、CI 一步；补 `CLAUDE.md`；加 D7 勘误注。

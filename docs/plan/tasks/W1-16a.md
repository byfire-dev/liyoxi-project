## 1. 目标

- 一张交付工单能从“待分配”走到“待上线”，并随上线任务的变化进到“上线核验”“服务中”：分配交付经理 → 推方案、商家确认 → 登记样片、质检、推送、商家确认 → 登记成片、逐集与成片包质检 → 推送成片包。
- 系统求值类迁移只有一个入口 `reevaluate()`，多调一次无害；每 5 分钟的补偿扫描把卡住的工单捞出来。
- 使用方：W1-17（开工时建工单）、W1-16b（下载签发）、W1-19、W1-20（页面）、W1-21（端到端脚本）。

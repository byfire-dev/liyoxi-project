## 1. 目标

交广告列表、详情2新页和列表内制作需求弹层，补“我的”/建档首页真实广告角标。
0新增API/x01；广告冻结/扣减、版本和查看事实全由W5-08/09，不另建页面状态机。

| 页面key / route | 本包边界 |
| --- | --- |
| `sub/ad/ads/index` | 广告队列、状态页签、报价后制作需求M42弹层；弹层不计第三页 |
| `sub/ad/ad-detail/index` | 当前版/历史版、允许的播放/查看出口、确认、修改与退回补充再提交 |
| `pages/mine/index`、`sub/profile/profile/index` | 已有页的广告待确认/三态计数和合法导航，不新增聚合接口 |

| 消费operationId（非接口归属） | 行为 |
| --- | --- |
| `m.ad.list`、`m.ad.get` | 游标/状态/详情、剩余免费修改数、影响订单与真实actions |
| `m.ad.quote`、`m.ad.create` | 服务端计价、协议版本、闸门和expectChargePoints，提交才冻结 |
| `m.ad.submit` | 退回后补充实际素材/文案，不重复冻结原需求 |
| `m.ad.confirm` | 当前versionNo、真实confirmableVia首项、hasViewed与已查看勾选 |
| `m.ad.requestChange` | 实际版本、分段/时间段/整条、说明/截图、超次实际积分确认 |
| `m.ad.downloadUrls`、`m.playable.get` | 每次现签与过期换址；不持久缓存或伪造查看事实 |
| `m.me.overview.get`、`m.storeProfile.get` | W5-08公开广告事实端口的真实角标，不从列表数量猜总计 |

请求/响应从`@liyoxi/contract/types/merchant`的operations推导，只消费W5-08/09实际schema，不复制DTO。
仅老板/ad.request、ad.confirm有相应能力；店员不发受限请求，不用隐藏按钮冒充后端权限。
价格、免费次数、超次收费与可选类型/时长以本次quote/GET为准；0与null不混淆。
当前门店/协议/输入改变废弃旧报价与确认，写前刷新实际事实，同意图失败保原key。
确认绑定本次版本与实际查看证据；切版/迟到签名地址/换门店不得回填旧播放器或确认状态。
推送时previewChannels与当前开关分开，关闭后的相册兜底按actual typed，不改推送历史。
广告可以按实际规则分段反馈，样片A31不因此开放时间点；合成问题仍去原样片页。
“我的”与建档只消费后端聚合，不能把未注册返回0当已回补或前端叠加虚构计数。

## 5. 不做什么

- 不新增广告取消商家入口、需求第三页、支付页或M6电脑端会话。
- 不写广告计费/修改次数字段算法，不在客户端调用后台代录/指派/取消口。
- 不改公共request、播放器框架、Provider、DDL、层规则、权限与现签时长。
- 不将相册保存/下载失败、旧版记录或固定截图当真实查看证据。
- 不替Q9答复，不把虚构素材/假通道标真实广告投放或签署。

## 7. 验收

新增目标实现后定点执行；单worker/禁止文件并行，保留旧权限/上下文/计数断言。

| 命令 | 判据 |
| --- | --- |
| `pnpm --filter @liyoxi/weapp exec vitest run src/sub/ad/private/model.test.ts src/sub/ad/private/api.test.ts --maxWorkers=1 --no-file-parallelism` | quote变更/同key、超次确认、版本/查看证据、截图守卫、换店迟到及安全错误 |
| `pnpm weapp:shots -- --page sub/ad/ads/index --page sub/ad/ad-detail/index --page pages/mine/index --page sub/profile/profile/index` | 两页与原入口实际交互；请求/GET核真实计数、确认与补充，不仅静态截图 |
| `pnpm --filter @liyoxi/weapp typecheck`、`pnpm weapp:build` | actual DTO、条件出口及旧聚合兼容；生产包无离线fixture/凭据 |
| `node infra/ci/pages/generate.mjs`，再`node infra/ci/pages/generate.mjs --check` | 当前包串行生成，精确2新页；M42不增页，原G5-B保留，不等W5-15 |
| `pnpm lint:colors`、`pnpm lint:copy`、`pnpm depcheck` | 设计令牌、状态文案、签名URL和依赖方向通过 |

至少截图列表/空态、需求报价与协议、待确认查看证据、超次修改确认、退回补充及两聚合角标。
公开服务/HTTP造数复用W5-08/09目标/公共testing，GET核两版本与账本变化；H5离线运输证据分列。
反例含店员/跨店、资质或套餐受阻、旧版本、无访问证据、超次积分不足、上传拦截。
超时重放不多冻结/多扣减；签名URL不进持久缓存/日志，切上下文不提交旧意图。
合流只作代码/本机证据结论，真机播放、下载保存及真实渠道另记。

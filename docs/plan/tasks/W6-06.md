- orderItem列表/release/下载投影按05会话scope及01当前使用期重读；广告只读预览与验真消费W5-07/08真实事实。
- 每次短时地址签发经W1-16b访问审计及下载授权公口；单集/ZIP/清单分别守原TTL，签名失败不得假造成功访问。
- downloadUrls消费07已合ensureZip/peek与代次语义，202/失败/重试真实可解释；小程序既有逐集接口保持原能力与下载边界。
- downloadGrant.create校验当前版本/使用期/角色后重建授权；download.report只回报属于本人和当前授权的记录，重复保存只记一次。
- saved进度来自delivery_download_log真实saved/clientAckAt；GET不记成功，不把签发或播放当已存相册。
- clientError仅接原限流/字段脱敏链；公开验真不暴露内部身份/私钥/签名地址，E8/E11未验不得声称法律结论。

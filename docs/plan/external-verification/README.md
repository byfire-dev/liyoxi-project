## 1. 填写规则

默认：以下各条由 W0-04 定。

| 项 | 规则 |
| --- | --- |
| 文件名 | 编号的小写短名。表一：`vNN-<短名>.md`，V1–V19 各一个；V5 的两部分在同一个文件里分两节。表二：`<来源>-<项号>-<短名>.md`，每行一个；同一来源项拆成两行的，各一个文件 |
| 状态取值 | 未开始；进行中；已关闭（通过）；已关闭（按退路）；不做 |
| 结论 | 一两句话写清结果与对方案的影响；采用退路的，写明改了哪个工作包或开了哪个变更包 |
| 证据 | 链接到 CI 运行、产物、ADR 或截图文件；不贴文本。业主实测的写实测日期与机型 |
| “（推）” | 计划没有逐项写依赖的，本台账按计划 第 4.1 节的 E4 明细与所属工作包的依赖推出，标“（推）”；与计划冲突时以计划为准 |
| 汇总表 | 下面两张表是随 W0-04 手工给出的初始快照。汇总脚本到位前，各 PR 只改单项文件，不改这两张表；与单项文件不一致时以单项文件为准。脚本随 W0-30 的四个计数报表交付，到位后由脚本生成，按生成物处理，不手改（计划 第 9.3 节、第 13 节） |
| 改最晚关闭点 | 属计划变更：先改计划 第 8.6 节，在 `docs/plan/changes/` 记一条，再改本台账（计划 第 13 节） |

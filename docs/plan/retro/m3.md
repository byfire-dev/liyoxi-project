## 范围与装配

M3 冻结归属为 79 API、11 新页面、16 项 x01。本包不增加 API、页面、x01、依赖或数据库结构。

默认 M1 仍为二十集四路。原 M1 一次主链回归已通过，含 Vitest 启动共 62.15 秒，
测试内 57.29 秒；模型预算装配追加钩子后还需最终受影响验证。

新增内容演示仅调用后台 HTTP，公共前置种子排除旧 content 步骤，
共享字典只复用既有数据定义补缺项，不覆盖已有项。理解首段的正式日额度为零，
真实任务以 `budget_unconfigured` 降级，并非 Provider 未配置；后段通过 HTTP 保存非零额度，
再开启测试外部配置并执行正式理解任务。预算仍执行生产 Lua，连接和 key 归本轮隔离资源。
测试账本使用合法历史零用量夹具，不能据此宣称生产保守初始化、恢复历史费用或真实付费调用已验。

素材使用记录沿用生产去重口径：每个素材有一条订单参考和一条 `order_item` 采用记录。
两集使用相同素材不会重复累计采用次数，`adoptedCount=1`；不按成片数量推算采用记录。

必要目录伴随限于 `apps/api/test/admin-content.test.ts`、
`apps/api/test/admin-content-revisions.test.ts` 的真实 handler 集合与挂载校验，
以及 `apps/api/src/routes/hooks/ci.ts` 的契约 operationId 注册身份检查。
后者不修改回调算法，前者不改变接口行为或放宽门禁。

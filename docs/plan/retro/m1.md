# M1 合流回顾

本次交付是本地与 CI 的替身主路径。演示点 A、B 的开发者工具与真机手验、M0 业主看样及预发实跑仍待实际反馈，M1 整体退出不由自动化结果代替。

## 1. 实际范围与返工

计划第 6.4 节为 27 个工作包，实际任务书也是 27 本；W1-20b 是后台交付的检查点，不另算包。合流前 25 包已合入，余下 W1-21 合流和 W1-23 拆包文档；a/b 拆分、公共出口修复与门禁调整带来更多 PR，不改变编号和完整范围。接口的实际归属为 M0 3、M1 130，合计 133，以契约和官方计数为准，不沿用早期约 128/131 的估算。

曾遇到的返工包括 CSRF 协议/端口校验、不可空 DTO 与实际返回不符、交付元数据未就绪、页面刷新竞争、成功部署记录缺镜像事实绑定。各原 PR 已按单轮独立审查定点修复。合流脚本自身的版本号误取已修正；媒体完成接口原有短轮询使逐集串行运行超过 90 秒，改用四路独立文件并发后完整 20 集主链约 52 秒，生产轮询与验收时限保留。

M1 按文件并行开发，统一提交，随后独立审查。评审不反复重跑已绿套件；阻断修复由定点反例与最终 CI 闭环。环境工作流含真实门禁资格调整，独立 gate-change，不混入业务 PR。

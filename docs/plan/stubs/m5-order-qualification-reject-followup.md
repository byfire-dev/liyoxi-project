# 资质驳回后的订剧后续

| 项 | 内容 |
| --- | --- |
| 状态 | 已回补 |
| 留桩内容 | 非终局驳回的 order.rejected_stale 与终局驳回的整店 qualification_cancel |
| 骨架里的做法 | W1-17b 的关键订阅者按当前资质事实仅把待开工、无在途取消单改 qualification_rejected；不登记 rejected_stale 定时器、不创建取消申请。迟到 approved 不越过当前驳回结论 |
| 登记的工作包 | W1-17b |
| 回补里程碑 | M5（G5-A） |
| 回补的工作包 | W5-02；远端发布以对应PR合入main为准 |
| 依据 | W1-17 第 7、10.6 节；x01 第 2.5 节 order.onQualificationDecided；D3 第 6.1 节 |

## 回补结果

非终局驳回按真实当前资质轮次登记order.rejected_stale，在配置的七自然日到点且仍待开工、无在途取消、当前轮仍驳回时只发客服主管待办；重新提交、旧轮、恢复或已开工跳过。终局驳回走实际整店qualification_cancel申请，审批前不终止/退积分；仅全部原周期全额释放且参数允许才自动调用W5-01唯一执行器，其他进入真实审批。失败整体回滚。

证据为W5-02资格四条真库场景及18条申请/后续集合，含真实通知消费与执行结果；不替代其他M5包、真机或法务验收。

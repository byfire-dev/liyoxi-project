`createPayment(...).applyPayment(tx, { paymentTxnId, ctx? })` 是公共入账入口，W1-11b 对公确认在自己的事务内调用。W4-01/02已回补可信微信成功收款、真实回调、查询/关单、到期、成功收款订阅者与未入账扫描，数据守卫、收款入账位与 fulfill 操作键保持防重。孤儿成功收款只开唯一bill_only/bank_unmatched差异并返回orphan，不虚造主体、付款单或权益。

本机六DB/四HTTP风险聚合已验证渠道多入口仅一次入账、密文恢复、查询自愈留痕、取消未知结果与范围/C50。普通重放不自动关闭历史差异；显式restore/rebuild_order、差异解决与退款仍由后继包承接，不能将本桩整体置完成。E2真实商户、密钥及资金联调仍未验。

实现入口与完整约定见 `packages/services/src/billing/payment/README.md`。这项与既有 `m4-billing-fulfill-upgrade-topup.md` 同属计划第 7.3 节 M4 留桩。

## 1. 怎么打开

| 看哪一端 | 步骤 |
| --- | --- |
| 后台（浏览器） | 仓库根目录跑 `pnpm install --frozen-lockfile`，再跑 `pnpm --filter @liyoxi/admin dev`，浏览器开 `http://localhost:5183/dev/showcase`。不用起接口服务。页面顶部的目录跳到各组；“五类页面”一组里有五个样例页的链接 |
| 后台（只翻截图） | `pnpm admin:e2e` 之后看 `apps/admin/dist/e2e-shots/showcase-*.png`；CI 里是产物 `admin-e2e-shots` |
| 小程序（只翻截图） | `pnpm weapp:shots` 之后看 `apps/weapp/shots/dist/png/`；CI 里是产物 `weapp-shots`。这是 H5 近似，不是小程序的渲染：没有原生导航栏与胶囊，原生的按钮、输入框、开关、弹层的样子以真机为准 |
| 小程序（开发者工具） | ① 先办 E16：装微信开发者工具，申请小程序测试号，拿到它的 AppID（AppID 不是密钥）。② 仓库根目录跑 `WEAPP_APPID=<测试号的 AppID> WEAPP_GALLERY=1 pnpm weapp:build`。③ 开发者工具里“导入项目”，目录选 `apps/weapp`。④ 工具栏的编译模式下拉里“添加编译模式”，启动页面填 `sub/gallery/index/index`，编译后就是陈列的目录页。不给 `WEAPP_APPID` 时是游客模式，只能在模拟器里看，不能上真机 |
| 小程序（真机） | 在上一步的基础上点工具栏的“预览”，用手机微信扫出来的二维码，打开的是开发版（不需要体验版权限，不需要备案）。iOS、安卓各看一次；第 3 节与第 5 节是真机上要专门看的 |

## 4. 留给看样定的事项

都是规范没写、或与规范有出入而实现时取了一种做法的。不填就照“现在的做法”。出处里的“偏差”指各包状态文件（`docs/plan/status/`）的“偏差”表，细节以那里为准。

### 4.1 小程序（W0-27b）

| # | 事项 | 现在的做法 | 出处 | 结论 |
| --- | --- | --- | --- | --- |
| D1 | 按钮禁用的样子 | 灰底（`fill-disabled`）深字（`text-regular`），文字写原因；次按钮、危险按钮禁用时同样是灰底 | 规范 第 4.3 节；W0-27b 偏差 3 |  |
| D2 | 按钮提交中的样子 | 颜色不变，文字前面一个自己画的转圈图标，不可再点 | 规范 第 12 节；W0-27b 偏差 3 |  |
| D3 | 胶囊小按钮禁用 | 页面底色、辅助色字 | W0-27b 偏差 6 |  |
| D4 | 文字按钮、图标按钮、列表行禁用 | 用禁用色（`text-disabled`） | W0-27b 偏差 6 |  |
| D5 | 复选框禁用 | 灰底 | W0-27b 偏差 6 |  |
| D6 | 开关禁用 | 整体不透明度 0.6 | W0-27b 偏差 6 |  |

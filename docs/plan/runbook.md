### 2.3 处置说明的写法

每条规则在本节下加一小节，按下面的栏写。默认：小节标题用“规则 N <名称>”（W0-04 定）。

| 栏 | 写什么 |
| --- | --- |
| 现象 | 告警长什么样；常见的伴随告警 |
| 先看 | 哪张表、哪个页面、哪条日志（按 `reqId` 查） |
| 判断 | 几种常见原因各自的特征 |
| 处置 | 每种原因的步骤；用到的 CLI |
| 不要做 | 会把事情弄糟的动作 |
| 升级 | 多久没恢复找谁 |
| 事后 | 要不要补不变量校验、补对账、记一条演练或事故记录 |

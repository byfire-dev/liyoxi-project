# 复审模板

依据：[开发计划](../../08-development-plan.md) 第 5.3 节“复审”“合并条件”“评审分级”“门禁改动”行、第 10.1 节。

## 1. 怎么用

| 项 | 规则 |
| --- | --- |
| 谁启动 | PR 就绪后，由业主或调度会话启动一个复审会话。复审会话不是该 PR 的作者会话 |
| 输入 | PR 差异、任务书（`docs/plan/tasks/<编号>.md`）、任务书“依据”所列的文档。默认：另加 `CLAUDE.md`，它是每个包的依据文档（W0-04 定） |
| 默认：非工作包 PR（W0-04 定） | `gate-change`、依赖升级、构件、台账这类单独的 PR 没有任务书。A 类按 PR 描述第 1 节声明的类型与范围查：只动该类型该动的文件；B 类按 PR 描述“怎么验”自己列的条目查 |
| 输出 | 按第 3 节的模板发一条 PR 评论，并打 `agent-reviewed` 标签。标签不存在时不自己建：在评论里写明“标签未建”，请业主按 [业主清单](../owner-checklist.md) 第 4 节建 |
| 复审不做什么 | 不改代码，不推提交，不合并，不放宽验收 |
| 意见不一 | 复审与作者意见不一时交业主裁决 |
| 合并条件里的位置 | CI 在“已与 main 同步”的提交上全绿 + 复审无阻断项（`agent-reviewed`）+ 业主本人点合并 |
| 默认：何时打标签（W0-04 定） | 结论为“无阻断项”才打 `agent-reviewed`；有阻断项不打，作者修完后重新复审 |
| 默认：标签何时失效（W0-04 定） | 打标签后作者又推了改动内容的提交，须重新复审。维护会话做的变基与重新生成不算 |

## 2. 四类阻断项

阻断项只有这四类。其余意见一律记为非阻断项。

| 类别 | 定义 | 怎么查 |
| --- | --- | --- |
| A 超出任务书范围 | 改了“允许改动的目录”之外的文件；做了“不做什么”里的事；新增了任务书没允许的依赖；把别的工作包的内容带了进来 | PR 的文件清单逐个对任务书第 4、5、6 节 |
| B 验收缺证据 | 任务书“验收”的任一条没有对应的“命令 + 判据”结果；证据不是 CI 运行或产物的链接（贴文本不算）；甲类包没附性质或并发测试输出；页面包没附截图；PR 模板有节没填（写“无”或“不适用”算已填）。默认：CI 就绪（W0-03 合并）前的包，证据按任务书写的办法给：命令与输出贴 PR 评论、描述里链接；复审会话在干净检出上重跑并把结果写进复审评论，重跑不过即 B 类；W0-03 的首次 CI 运行补证（W0-04 定） | PR 描述“怎么验”逐条对任务书第 7 节，点开链接看结果 |
| C 门禁被放松 | “放松”类改动出现在工作包 PR 里：删改已有规则或已有黄金条目、调高基线、删 CI 步骤、改 `layers.json` 白名单、改锁序常量；或用跳过、条件绕开等办法让检查不生效 | 看 PR 描述顶部 CI 列出的门禁改动清单与差异；看 `gates:selftest` 是否为绿 |
| D 与依据文档不符 | 实现与任务书所列依据（01–07、docs/api、docs/data-model、规范、计划）不一致，且没有在同一 PR 回写文档并在“偏差”里列出；触犯计划 第 5.3 节“禁止”行；违反 `CLAUDE.md` 第 6 节的硬性规则 | 对任务书“依据”表逐条核对；对 `CLAUDE.md` 第 6 节逐条过一遍；看 PR 描述“留桩与偏差”“回写了哪些文档” |

按评审级别加看（计划 第 5.3 节“评审分级”行）：

| 级别 | 复审重点 |
| --- | --- |
| 甲 | 没有与其他改动混合；按机制分提交；性质或并发测试输出齐全 |
| 乙 | 验收输出、对账差异、默认项清单 |
| 丙 | 截图与清单 |

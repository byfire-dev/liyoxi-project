# 工作包状态文件模板

用法：复制为 `docs/plan/status/<编号>.md`，删掉“---”以上的部分。依据：[开发计划](../../08-development-plan.md) 第 13 节“进度记在哪”行、第 9.3 节。键的写法、状态取值与谁在何时改，以 [status/README.md](../status/README.md) 第 2、3 节为准；本模板照它写，两边不一致时改本模板。

- 一包一个文件，由该包的 PR 自己更新，不改别的包的文件。
- 汇总表由脚本生成，按生成物处理，不手改。“项”一列是脚本读的键：不改名、不加列、不调序。
- 空值的写法：PR、依赖没有时写“—”；阻塞原因、“偏差”“留桩”两节没有时写“无”；结构变更包写“是”或“否”。
- 计划 第 13 节只列了状态、PR、阻塞原因、偏差；其余的键是默认（W0-04 定）。

| 评审级别 | <!-- 甲 / 乙 / 丙 --> |

内容、依据与验收见[开发计划](../../08-development-plan.md) 第 <N> 节 <编号> 一行。写法见 [README.md](../status/README.md)。

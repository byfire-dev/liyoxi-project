# 留桩登记模板

用法：复制为 `docs/plan/stubs/<文件名>.md`，删掉本段。依据：[开发计划](../../08-development-plan.md) 第 13 节“留桩清单”行、第 5.7 节“实现进度”行、第 7.3 节表后的留桩清单、第 9.3 节“端口”行。何时登记、命名与计数，以 [stubs/README.md](../stubs/README.md) 第 2–4 节为准；文件里的键以本模板为准。

- 一项一个文件，写明骨架里的做法与回补的里程碑。留桩数由 CI 统计（状态为“留桩中”的文件数）。
- 文件名：`<回补里程碑>-<模块>-<短名>.md`，如 `m4-ops-probe-funds.md`。一个回补点一个文件；一项有多个回补里程碑的，按回补点拆成多个文件。
- 不许留桩的：内核、账本、鉴权链；提交校验这类正确性逻辑。
- 不算留桩的：“入口隐藏”的页面，在 `docs/plan/pages.md` 里标注，不在这里建文件。
- 计划 第 7.3 节留桩清单之外要新留桩的，先改计划的留桩清单，并在 [changes/](../changes/README.md) 记一条，类别写“留桩”。
- 回补时不删文件：回补的 PR 把状态改为“已回补”并填 PR 编号。
- “项”一列是 CI 读的键：不改名、不加列、不调序。

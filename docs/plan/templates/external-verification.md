# 外部验证项模板

用法：复制为 `docs/plan/external-verification/<文件名>.md`，删掉本段。依据：[开发计划](../../08-development-plan.md) 第 8.6 节（两张表）、第 13 节“外部验证台账”行、第 2.3 节。文件名、状态取值与填写规则，以 [external-verification/README.md](../external-verification/README.md) 第 1 节为准；本模板与它保持一致。

- 一项一个文件，记结论、证据、最晚关闭点。计划 第 8.6 节两张表现有各行的文件已随 W0-04 建好；本模板用于以后新增的验证项。
- 文件名：表一 `vNN-<短名>.md`（V5 的两部分在同一个文件里分两节）；表二 `<来源>-<项号>-<短名>.md`，如 `d7-02-release-channel.md`。
- 新增或改最晚关闭点属计划变更：先改计划 第 8.6 节，在 `docs/plan/changes/` 记一条，再改台账。README 的两张汇总表是 W0-04 给的初始快照，不再更新，以单项文件为准；现在的汇总跑 `pnpm plan:summaries` 现生成。
- 到最晚关闭点未关闭：依赖它的工作包不开工；写了到点退路的按退路。
- 技术验证包（X-01–X-04）的结论另写成 ADR，并更新计划 第 8.6 节与本台账。
- 证据只放链接（CI 运行、产物、ADR、截图文件），不贴文本；不放密钥、证书、完整手机号。
- “项”一列的键不改名、不加列、不调序。

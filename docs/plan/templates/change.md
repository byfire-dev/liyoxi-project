# 计划变更记录模板

用法：复制为 `docs/plan/changes/<文件名>.md`，删掉本段。依据：[开发计划](../../08-development-plan.md) 第 13 节“计划变更怎么记”行、第 5.7 节、第 5.3 节“粒度”行。何时登记与命名，以 [changes/README.md](../changes/README.md) 第 2、3 节为准；文件里的键以本模板为准。

| 类别 | 范围 | 做法 |
| --- | --- | --- |
| 小改 | 包的拆并、顺序调整、估算修正；接口、页面、x01 条目改归属；留桩清单的增改 | 直接改开发计划，同一个 PR 在本目录记一条 |
| 大改 | 里程碑范围、退出条件、前提 | 不在这里记。PR 标 `plan-change`，须业主确认 |
| 不在这里记 | 架构取舍 | 另写 ADR（`docs/adr/`） |
| 不在这里记 | 待确认事项有了结论 | 先改文档里的默认做法，再改代码，同一个 PR；必要时开“变更工作包” |
| 不在这里记 | 实现与任务书的出入，不改计划 | 写在该包状态文件的“偏差”与 PR 描述 |

- 一条一个文件。汇总表由脚本生成，不手改。
- 文件名：`<来源>-<短名>.md`。来源写触发变更的工作包编号，不由某个包触发的写 `plan`；短名用英文小写加连字符。如 `W0-13-split-a-b.md`。不用流水号，免得并行的 PR 抢号。
- 没有内容的写“—”。

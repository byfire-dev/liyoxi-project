# 账号设置（W2-13）

## 交付范围

仅登记 `sub/service/settings/index` 一页。本人称呼、旧号短信与新号码授权换绑、微信身份分页及解绑、
服务器一次性提示关闭、退出、注销均消费已有本人接口。账号按钮取服务端 actions，注销阻断项
只展示服务器返回的六类及数量。隐私与用户服务协议使用当前版本；通知进入已有消息与订阅页。
已授权电脑沿 W6-10 的既有商家接口展示本人在当前主体下的有效授权；老板可显式撤销，
也可通过“授权电脑”或“输入授权码”进入已有电脑审批页。不包含电脑下载业务或真机扫码结论。

## 操作与失效

私有 model 同步持有写忙锁，失败同意图复用键、修改内容换键；确认成功立即结束该意图，
不因后续刷新失败让未来 A/B/A 复用第一次 A 的回执。token/contextRev、读代次及写后刷新
废弃旧响应，旧 finally 不解除新所有者的锁。卸载清理本页控制器。

换绑失败为实际可重试错误时，仅在私有内存保留未决 body 与原键，通过“重试上次换绑”重放；
编辑旧验证码、另取新授权、成功、非重试失败、关闭弹层或卸载时销毁。不日志或本地持久化
手机号、短信码、临时号码凭证。换绑保留当前令牌；服务端返回当前身份已吊销、注销成功或
当前请求最终 401 时沿公共 account.clear 清会话与门店上下文。

## 电脑授权管理（W6-10 候选增量）

电脑管理仅对当前门店老板开放，老板停用门店仍沿原收尾权限；店员不发列表/吊销请求。
列表打开后才调用 `m.portalSession.list`，无分页、无写参数；不按当前店过滤服务端返回的
主体内其他门店授权。只展示实际浏览器、地区、门店和授权/到期时间，不制造 status/actions
或“当前电脑”字段。空态只在真实 GET 返回空数组后显示。

显式确认后调用 `m.portalSession.revoke`，保留中央请求的当前身份/门店与 required 幂等键。
同意图失败可重试，取消或新意图换键；单写锁拒绝重复点击。成功保留真实回执并重新 GET，
不乐观删除列表项。读回失败保留操作结果，重试只重新读列表；已经过期的 200 回执不伪造
revokedAt 或新增撤销事实。电脑端下一请求失效由实际 API/HTTPS 验收证明，页面移除不是该证据。

电脑列表有独立读代次；关闭、写入、卸载、切店、换令牌或老板资格变化后旧响应不得恢复列表
与确认。页面 scope 同时包含当前成员/主体/角色身份，资格变化清本页；当前 401 沿公共清态
与登录返回，迟到 401 不清新会话。原小程序退出语义不变，不把退出小程序当作撤销全部电脑。

新增定点反例在 `portal-sessions.test.ts`，实际 typed 传输在 `runtime.test.ts`，原 W2-13
用例保留。作者仅静态实现，完整类型/测试/构建、截图与实际 API 整链由 ROOT 执行后记录；
本段不代表已完成这些检查，也不代表 V8、X-01 或整包条件已通过。

## 手机号与公共边界

PhoneForm 与换绑使用 Taro 原生 getPhoneNumber Button，先经现有 ensurePrivacyAuthorized。
拒绝授权、隐私未同意或额度不足均不伪造号码；H5 明示不支持号码验证。登录继续既有协议版本、
loginCode、首次归因与 returnUrl/query。公共 controller 仅修 phoneLogin 的 opaque code 参数
及 1–128 字符校验，其他公共 API/runtime/request/platform/bootstrap 没有改动。

# 狸有戏官方品牌素材

由业主于 2026-11-03 提供并授权用于本小程序，来源为品牌视觉体系
`full-vi-production-v1/assets/logo/`。本目录保留三份 PNG 原文件与文件名，
不重绘、不改色、不拉伸；只用于浅色安静背景。™ 为页面独立排版的商标标记，
不修改原图，不使用注册商标符号。

品牌标语按业主本次确认统一为「让好生意，更有戏」，用于登录页及设置页品牌署名。

| 文件 | 使用位置 |
| --- | --- |
| `07-wordmark-transparent.png` | 首页自绘导航，保留胶囊避让 |
| `04-horizontal-lockup-transparent.png` | 商家登录页主品牌；CSS 仅收起原图透明空白，完整保留图形和字标 |
| `08-app-icon-light-1024.png` | 设置页底部，64px 品牌图形与署名 |

素材随包加载，不依赖 COS、MinIO 或远程签名 URL。平台品牌不替换门店头像、
服务经理头像、短剧封面，也不叠加到商家定制成片。这里的图形使用不修改
微信公众平台配置的小程序头像，后者由平台管理单独配置。

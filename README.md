# 狸有戏（liyoxi）

面向本地生活商家的短剧营销工具：平台把自有版权短剧按门店定制成片并植入商家广告，商家在自己的抖音号、视频号上线，为门店引流。

V1.0 交付商家端微信小程序、运营管理后台与商家电脑端下载页。

## 当前状态

技术架构与选型评审稿已完成，尚未开始编码。

# 设计提取报告

从原型源码里提取设计规范时的工作底稿（四份报告加一份统计数据），供查出处与用量时使用。**取值以 [../design-spec.md](../design-spec.md) 为准**：底稿里标“建议”的内容是分析时的意见，规范定稿时有取舍，两者不一致时按规范。

| 文件 | 内容 |
| --- | --- |
| [tokens.md](tokens.md) | 颜色、字体、间距、圆角、阴影、尺寸的用量统计与对比度计算 |
| [components-merchant.md](components-merchant.md) | 商家端小程序的页面骨架与组件规格，NutUI 的使用建议 |
| [components-admin.md](components-admin.md) | 运营管理后台的框架、页面类型与组件规格，Ant Design 主题建议 |
| [patterns.md](patterns.md) | 与 PRD 8.3 的逐条核对、业务状态取色、反馈与表单、文案、图标、封面占位、无障碍、平台约束 |
| [stats.json](stats.json) | 对两端源码的内联样式做的用量统计（颜色、字号、圆角、间距等） |

说明：

- 出处写作“画板名:行号”或“画板名 L行号”，指 `../prototype/<端>/src/<画板名>.dc.html` 的源码行。
- 用量是脚本对源码全文的计数，不同报告的统计口径略有差别（按出现次数、按文字节点数、按画板数），各报告开头有说明。
- 报告里提到的“参考工程”指 `timavia-liyo-project`，其文件路径不在本仓库内。
- 这些报告对应 2026-10-02 的原型快照，原型更新后不会自动更新。
- 规范定稿前请五位复核员对照源码查过一遍，底稿里被查出的错误（如后台缩略图尺寸、后台次按钮描边的取值个数）已在规范里更正，底稿本身没有回改。

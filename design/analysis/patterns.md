# 狸有戏 · 页面模式与交互规范（从原型提取）

> 依据：商家端原型 47 个画板（`prototype/merchant/src/*.dc.html`）、后台原型 56 个画板（`prototype/admin/src/*.dc.html`）、`stats.json`、渲染截图、PRD 第 8.3 节。
> 引用写法：`画板名 L行号`；未加前缀的画板名，M 开头章节指商家端，其余按表头注明的端。
> 标记：**【源码】** = 原型里明确如此（数值照抄）；**【建议】** = 本报告的归纳或建议，需确认后才进规范；**原型未画** = 全部源码中检索不到。
> 统计口径：对全部源码做正则计数（去掉 `<svg>` 与 `style` 后匹配文本），数字是“出现次数”，不是“画板数”，除非写明。

## 1. 与 PRD 8.3 逐条核对

### 1.1 平台规范（原生导航栏、胶囊区不放操作）

| 核对项 | 结论 | 出处 |
| --- | --- | --- |
| 顶部导航栏 | 【源码】47 个画板全部画了 `<header>`，高 `48px`；44 个是同一写法（标题居中 `17px/600`，左侧 `44×44` 返回） | 统计：header 写法 44 个相同；另 3 个不同：`Trailer`（绝对定位）、`Login`（无标题）、`Orders`（带白底） |
| 胶囊区 | 【源码】47 个画板都在 `right: 8px; top: 8px; width: 87px; height: 32px` 画了胶囊占位（`aria-hidden`），该区域内没有任何可点元素；header 里的可点元素只有左侧“返回”（`PayResult` 为“返回首页”，`left: 2px`） | 全部画板；`PayResult` header |
| 不符合“原生导航栏”的画板 | 【源码】① `Main L20` 标题是品牌字 `'Noto Serif SC' 19px/900`“狸有戏”，原生导航栏不能换字体与字号；② `Trailer L22–24` 导航栏 `position: absolute` 叠在整屏深色画面上，返回键旁带文字“列表”，白字；③ `Login` 无标题；④ `Orders` 的 header 带 `background: #FFFFFF`，其余透明（露出页面底色 `#F6F3EE`） | 见左 |
| 状态栏、安全区 | 原型未画（画板从导航栏开始，底部栏无安全区留白；底部导航 `height: 64px; padding-bottom: 8px`，`Main L120`） | — |

【建议】默认用原生导航栏（标题 17px 系统字，底色 `#F6F3EE`）；`Main` 改用系统字标题或单独声明自定义导航；`Trailer` 若保留必须自定义导航，并用 `getMenuButtonBoundingClientRect` 避开胶囊。底部导航带角标（选剧单“2”），用原生 tabBar 的角标接口即可。

### 1.2 字号层级（PRD：标题 17 / 正文 15 / 辅助 13 / 标签 12，系统默认字体）

| 字号 | 商家端次数 | 是否在 PRD 层级内 | 实际用途【源码】 |
| --- | --- | --- | --- |
| 17px | 79 | 是 | 页面标题（46 个画板）、底部弹层标题（`Ticket` 撤回工单 `17px/600`） |
| 15px | 254 | 是 | 正文、卡片标题、输入框文字、主按钮 |
| 13px | 468 | 是 | 辅助说明、提示条、状态文字 |
| 12px | 515 | 是 | 标签、角标、计数 |
| 14px | 259 | **否** | 表单标签（`14px/600`，35 处 `<label>`）、次按钮、选项胶囊、文本域 |
| 16px | 88 | **否** | 大按钮（`Login L50` `16px/600`）、卡片主标题 |
| 11px | 48 | **否** | 头像字、缩略海报标题 |
| 10px 及以下（10/10.5/9.5/8/7） | 约 33 | **否** | 缩略海报竖排标题（`MyDramas L43` `9.5px`）、媒体角标（`Profile L42` `10px`）、广告画面示意里的字（`Ads L53` `8px`） |
| 18–46px | 约 70 | **否** | 数字强调（22/26/28）、品牌与海报大字 |

- 字体【源码】：47 个画板根节点都是系统字体栈 `-apple-system, BlinkMacSystemFont, 'PingFang SC', …`；另有 `'Noto Serif SC', serif` 73 处（品牌名、海报标题、头像字、“专业版”26px、日期大字 24px），由 `fonts.googleapis.com` 外链加载（各画板 `<helmet>`）。
- 与 PRD 不一致：PRD 只有 4 级且要求系统默认字体；原型常用 6 级（12/13/14/15/16/17），并大量用衬线字。
- 后台【源码】：13px 1,666 次、12px 1,393 次、14px 1,219 次；页面标题 `h1` 56 个画板统一 `'Noto Serif SC' 24px/700`；弹窗标题 `18px/600`。PRD 8.3 没有规定后台字号。

### 7.2 正式素材到位后的替换规则【建议】

1. 封面统一用 3:4 竖图（PRD 751 行“竖版封面”），`object-fit: cover`，圆角沿用上表；缩略图全部改成严格 3:4。
2. 有封面图时去掉竖排标题与内描边（标题已在图里）；角标、题材文字保留，位置不变，题材文字下加一层自下而上的暗色渐变保证可读。
3. 每部剧保留一个主色字段（后台数据里已有 `color`），作为图片加载前与加载失败时的底色。
4. 没有封面或加载失败时，回退到现在的“色块加竖排标题加内描边”，这套占位即兜底样式。
5. 失效态规则不变：整张图加灰并降低不透明度。
6. 竖排标题用的衬线字需单独解决字体加载（小程序内不能依赖外链字体），见待确认问题。

# 设计

「狸有戏」的界面依据都在这个目录里，开发不依赖 Figma。

| 内容 | 位置 | 用来做什么 |
| --- | --- | --- |
| 设计规范 | [design-spec.md](design-spec.md) | 颜色、字号、间距、组件规格、状态取色、文案规则；原型没画的状态怎么补；哪些地方不能照原型做 |
| 样式变量 | [tokens.json](tokens.json) | 规范里通用取值（颜色、字号、间距、圆角、尺寸、阴影）的机器可读版本，两端的样式变量与主题由它生成；组件级的规格仍看规范 |
| 原型快照 | [prototype/](prototype/README.md) | 商家端 47 个画板、后台 56 个画板的源码与完整截图，每一页的布局、文案与交互以它为准 |
| 提取报告 | [analysis/](analysis/README.md) | 规范取值的出处与用量统计，需要追溯时查阅 |

先读设计规范的第 0 节。

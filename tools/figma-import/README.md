# 狸有戏原型 → Figma 导入插件

把两套原型（商家端 47 个画板、运营管理后台 56 个画板）生成为 Figma 原生图层：画框、可编辑文本、矢量图标。

- 目标文件：<https://www.figma.com/design/cc7w65GwQ0zrOhMPE77GAs>
- 数据来源：2026-10-02 的原型版本，已内嵌在 `code.js` 里，运行时不联网。

## 为什么需要这个插件

通过 Figma 连接器生成到一半时，触到了 Figma 免费版（Starter）每月 20 次工具调用的上限。此时文件里的状态是：

- “商家端小程序”页：47 个画板已生成，但还没有按流程分组排好，页面上另有 6 个灰色的数据占位层。
- “运营管理后台”页：只有 7 个数据占位层，画板还没有生成。

本插件在本地运行，不占用连接器额度。它会清掉占位层，重新生成全部 103 个画板，并按原型的分组排进分区。

## 运行步骤

需要 Figma 桌面版（从清单导入插件只在桌面版提供）。

1. 用 Figma 桌面版打开上面的目标文件。
2. 菜单：Plugins → Development → Import plugin from manifest…，选择本目录的 `manifest.json`。
3. 菜单：Plugins → Development → 狸有戏原型导入。
4. 等待右下角提示“导入完成”。后台页图层较多，全程约 1–3 分钟，期间界面可能短暂无响应。

可以重复运行：同名的画板与分区会先删除再重建。在别的文件里运行也可以，页面不存在时会自动新建（免费版每个文件最多 3 页）。

## 与原型的差别

- **字体**：原型用系统字体（苹方），Figma 里用思源黑体（Noto Sans SC）与思源宋体（Noto Serif SC）。Figma 提供的思源黑体没有 600 字重，原型里的 600 用 Bold 代替。
- **长页面完整展开**：原型里要滚动才能看到的内容全部展开，所以手机画板的高度不是 844，而是内容的实际高度。
- **只有默认状态**：可交互画板（弹层、切换页签、展开表单）只导入打开时的默认状态。
- **绝对定位**：图层按原型的像素位置摆放，没有使用自动布局，也没有建组件、样式与变量。适合评审与标注；要作为正式设计稿继续做，需要设计师整理成组件与自动布局。
- **竖排文字**：Figma 没有竖排，用“一字一行”近似。

## 验证情况

- 商家端 47 个画板已通过连接器在 Figma 里生成，过程无报错；其中“M02 首页”与浏览器渲染做了并排比对，位置与样式一致。其余画板没有逐个比对。
- 本插件的生成逻辑与上述过程相同；分区排版与清理占位层的部分只在模拟环境里跑通，没有在真实的 Figma 里运行过。
- 后台 56 个画板还没有在 Figma 里生成过。

## 原型更新后重新生成

`pipeline/` 里是转换脚本：`extract.mjs` 用本机 Chrome 无界面渲染每个画板并提取布局，`plan.mjs` 生成分组，`gen-plugin.mjs` 把数据嵌入 `plugin-template.js` 得到 `code.js`。脚本里的路径常量 `S` 指向当时的临时工作目录，重跑前需改成原型文件所在的位置。
